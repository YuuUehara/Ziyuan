# 1.0.0-rc.1 验收清单

冻结于 2026-10-29（下一步开发计划 Phase 0）。rc.1 发布前逐条勾销；rc 期间只修本清单内的阻塞缺陷。

**阻塞发布的缺陷类：**未经批准写入、未隔离执行被误报为已隔离、审计记录与真实操作不符、恢复后重复不可逆副作用。

- [x] **RC-01 真实模型全流程**：DeepSeek 跑通下诏 → 承办 → 复核 → 准奏提交 → 驿站 → 草稿 PR 全链路；任务 ID、模型、token 与耗时记入本文件「执行记录」。（2026-10-30：第 1 轮通过，见执行记录）
- [x] **RC-02 审批与落盘**：未批准不写盘，批准范围外不改；`apply --commit` 的提交只含本诏令文件；改动预览带 `base_hash` 并在落盘前重验（审批 TOCTOU）。（未准奏前文件不存在；提交 7f0b22d3 只含 docs/rc1-smoke.md；预览后在本地抢先建同名文件 → `stale: true`、`apply` 拒绝「已被改动」，删去后照常）
- [x] **RC-03 中断与恢复**：中断后状态明确；重放不重复外部副作用（幂等键）；重试不重复提交 PR、评论或 git 提交。（真实 GitHub 上：重复 `reply`/`pr` 被拒；截去事件簿末尾的 REPLIED 模拟「已发未记」后重试，按幂等键找回评论 6503501654 与 PR #2 补记，未发第二次；`apply --commit` 重跑认出同一提交 7f0b22d3）
- [x] **RC-04 GitHub 链路**：issue 与成员 `/ziyuan` 评论入队、评定后回报、准奏开草稿 PR，关联可追踪。（issue #1 带 `ziyuan` 标签入队 → 评定后回报评论 → 准奏开草稿 PR #2，评论与 PR 正文带幂等标记；验收后关闭）
- [x] **RC-05 跨平台说明**：Linux/macOS/Windows 的支持范围在 README、SECURITY.md 与指南中如实分述；CI 分开设明「Windows 功能可用」与「号舍暂缺」。（README 新增「平台支持」表；SECURITY.md、指南与 ADR-0001 同述；CI 作业名分为「macOS · 功能与号舍」「Windows · 功能可用 · 号舍暂缺」）
- [x] **RC-06 兼容**：旧事件簿、会典、配置与 `.ziyuan/` 文件照常可读；契约测试与 `ziyuan migrate` 全绿。（契约测试全绿；`ziyuan migrate` 读本轮事件簿：49 条、可读，所需版本 1.0.0-rc.1，首个新事件为第 45 行 dispatched）
- [x] **RC-07 沙箱负向**：要求号舍而不可用时受保护操作被拒且错误可审计（`auto` 与 `require` 均拒，错误为 `SandboxUnavailable`）；`off` 显式标注无隔离。（Task 4：auto 与 require 在无号舍平台均拒，`SandboxUnavailable`；CI windows-latest 断言拒绝；`off` 在结果中注明无隔离）
