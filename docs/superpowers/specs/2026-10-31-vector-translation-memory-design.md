# 向量翻译记忆库开发设计

状态：方向已批准，书面设计待审阅；本文规划后续开发，不立即实现。

## 目标与顺序

从当前有效的御览定稿中检索相似原文及对应译文，给翻译者提供可追溯参考，减少长篇作品的不一致。它是翻译记忆库，不是术语表的替代品，也不是自动定稿功能。

排在 1.2.2 临时文件清理之后，并依赖译书写入安全及可信读取协议。具体小版本和日期待阶段验收范围确定，不提前承诺。延续[路线图](../../roadmap.md)的通用索引生命周期、内容适配器、范围过滤、检索与提示分离原则。

## 已有基础与方案选择

`TranslationFinalized` 具有项目、块、译文摘要、上下文与朱批版本；`TranslationReopened` 记录退回。`translation/status.rs` 还结合磁盘事实判断定稿、版本失效或不确定。事件出现过定稿不等于当前仍有效；收录不能只订阅新增定稿事件。

采用“权威资料 + 可重建派生索引 + 独立嵌入接口 + 带来源候选”。不把向量数据库作为译稿事实来源；不先做仅按定稿事件追加、从不失效的简化库；不提前指定模型、向量数据库或远程服务。

## 数据契约

一项对应一个源文段落 ID 的原文／译文对。块定稿后按 ID 配对，不按数组位置猜配；ID 缺失、重复或结构检查不通过则不收录相关块并报告。

每项至少记录：

- 工作目录／项目身份、内容类型、源语言与目标语言、章节、块、段落 ID；
- 原文与译文，以及各自内容摘要、块级原文／译文摘要；
- 定稿事件的事件簿位置与可复核身份、上下文版本、朱批版本及相关内容摘要；
- 嵌入输入摘要、嵌入提供方／模型标识、模型修订或可用版本信息、维度、距离度量、索引格式版本；
- 构建水位与失效状态，足以追溯原始资料，不以向量相似度代表批准状态。

逻辑身份由工作目录、项目、块和段落组成；版本由资料摘要与定稿来源区分。重新定稿替换现行版本，不能让旧版本继续作为有效命中。工作目录迁移须重新绑定来源或重建，不以绝对路径字符串偶然相同认定同一资料。

## 可信读取与生命周期

索引只能从当前 `Finalized` 且所有版本核验通过的权威状态建立。事件簿、原文、已准奏译文及批准记录为事实来源；索引可删、可损坏、可重建，不能反向更改这些资料或批准状态。

构建使用事件簿位置和稳定偶数世代作为覆盖水位，记录事件历史身份／摘要。读取前后水位相同、无未完成业务恢复记录才能发布；奇数世代、历史变化或不稳定读取时停止发布并报告，不把部分结果标为最新。

增量处理不仅看新增定稿事件，还覆盖退回、上下文／朱批变化、原文或译文缺失及手改。外部编辑不推进世代，因此使用候选前仍须核验依赖内容摘要；不能只比较偶数世代。

退回、版本失效或不确定的项立即不具备检索资格。索引滞后时先同步；无法同步则明确返回记忆库不可用或无参考，不能悄悄使用旧定稿。检索后至提示组装前再核验命中资格，若资料变化则丢弃候选。该核验只证明读取时状态，不保证远程模型执行期间资料永不变化，写入门控仍独立生效。

以幂等更新、可重放游标处理重复事件及中断。派生索引使用独立的构建／发布互斥及完整性标记，不进入业务恢复记录，不为索引操作推进业务世代。重建先形成完整新索引再切换；中断、维度不符、模型变化、格式不兼容或损坏时拒绝混用并支持重建，原始资料不受影响。

## 嵌入、授权与数据边界

嵌入接口独立于聊天模型，不假定聊天端点支持 embeddings。默认不开启远程嵌入；本地实现与远程实现是同一边界下的可替换提供方，没有可用提供方时明确报告不可用，不悄悄外发。

远程嵌入必须按项目显式启用，并明确提供方、端点与发送字段。首版评估以原文为嵌入输入，译文及其来源本地保存；如选择其他输入，须更新输入契约及授权说明。查询文本同样属于外发数据，必须检查其所属项目授权。更换远程提供方或扩大字段范围须重新授权。

允许跨项目检索时须显式指定所有目标项目范围，默认仅当前项目；授权项目不能替未授权项目开启上传。范围与权限在向量召回前生效，不先全库召回再只在提示中隐藏越权项。

日志不含原文、译文、查询正文或密钥。索引本身含用户文本，应沿用工作目录私有数据保护，不自动上传、共享或进入版本库。禁用远程提供方不等于撤回已经外发的数据，说明中必须区分。

## 检索与提示边界

检索接口接受已授权的项目、语言、候选上限和查询，组合精确／关键词与向量召回，返回有限候选、来源定位、摘要、定稿版本及检索分数。阶段一用基线确定融合及预算，不提前指定相似度阈值。

提示组装器独立消费候选，标为“参考译法”，保留引用和版本。参考内容视为数据，不作为指令；不覆盖术语、朱批或当前上下文，不自动采纳，不获得工具权限，不绕过准奏或御览门控。记忆库不可用时可以继续原有翻译流程，但须显示未使用参考，不能声称一致性已得到保障。

通用层只处理嵌入、记录身份、范围、索引生命周期与候选；翻译适配器处理段落配对和定稿资格，提示适配器处理译书注入。未来代码适配器另处理文件／符号、忽略规则、敏感内容与提交水位；首版不实现代码解析器、调用图或排序服务。

## 分阶段计划与验收门槛

| 阶段 | 交付 | 进入下一阶段的门槛 |
| --- | --- | --- |
| 一、数据契约与质量基线 | 固定记录与资格契约，日／英样本、关键词基线；比较存储、本地模型与可选远程模型 | 覆盖同义改写、人名、术语、对白、近似但不适用及无匹配；预先登记质量阈值、延迟／磁盘／费用预算和人工评测办法，确认选型 |
| 二、嵌入接口与可重建索引 | 独立嵌入接口、模型签名、范围隔离、完整构建与重建 | 默认零外发；未经授权项目与查询零上传；损坏、维度改变和中断不影响权威资料，重建结果可复核 |
| 三、增量与失效 | 定稿收录、退回／版本变化失效、幂等游标与水位 | 同块重定稿、漏事件／重复事件、历史不符、磁盘手改、奇数世代、恢复未完成及构建竞争均不返回失效项 |
| 四、混合检索与参考注入 | 先过滤范围的混合检索、引用展示、独立提示组装与预算 | 与无记忆库和关键词基线对比，记录命中率、错误参考、术语一致性、人修时间、tokens、费用和延迟；人工双语评测通过，模型互评不能替代 |

数值阈值和具体后端在阶段一评审时确定并冻结，不能事后为“通过”调整。本规划不代表已经证明文学收益；若收益不足以抵消成本，停止扩大或保留关键词方案，不强推向量化。

## 非目标与后续入口

首版不收录未定稿初译、审校建议、朱批正文或札记为自动训练资料，不自动晋升术语，不训练／微调模型，不做跨用户共享库，也不承诺出版质量、代码检索或自动批量写入。

书面设计审阅后先编写 1.2.2 实施计划。记忆库阶段一另立实施计划和选型评审，再按阶段推进，不把整项功能隐含塞入 1.2.2。
