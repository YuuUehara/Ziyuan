# 1.47.0 验收记录

对应提交：本发布提交（`1.47.0`）。

## 核对项

1. **工部编程 Agent 暂存闭环工具（`staged_diff` 与 `revert_staged`）**
   - [`crates/ziyuan-runtime/src/tools/staged.rs`](../../crates/ziyuan-runtime/src/tools/staged.rs) 与 [`crates/ziyuan-runtime/src/tools.rs`](../../crates/ziyuan-runtime/src/tools.rs) 随既有 `Capability::WriteFile` 自动授予只读 `staged_diff`（可与只读工具并发执行，基于 `FileChange::hunks` 输出带 `[第 N 段]` 与 `+add -del` 汇总的统一 diff，支持按文件或子目录过滤，上限 32 KiB）与有界回退 `revert_staged`（支持单文件 `path` 或 `all: true` 清空暂存，还原至磁盘原文基线），严守玉玺范围与 `.ziyuan`／`.git`／`.jj`／`.env*` 禁区，不直接触盘。
   - [`crates/ziyuan-runtime/src/lib.rs`](../../crates/ziyuan-runtime/src/lib.rs) 在工部承办系统提示中同步开放 `staged_diff` 与 `revert_staged` 指引。
2. **`replace_text` 的 CRLF 行尾自适应精确匹配与 `read_file` 行号输出**
   - [`crates/ziyuan-runtime/src/tools/edit.rs`](../../crates/ziyuan-runtime/src/tools/edit.rs) 在目标文件为 `\r\n` 行尾而模型传入 `\n` 多行片段且字面匹配为 0 处时，自动按 `\r\n` 执行精确唯一匹配并将替换内容归一化为 `\r\n` 写入暂存（多处匹配仍照常报错列出歧义行号，行范围外完全匹配诊断同步适配 CRLF）。
   - [`crates/ziyuan-runtime/src/tools/read.rs`](../../crates/ziyuan-runtime/src/tools/read.rs) 新增向后兼容可选布尔参数 `line_numbers`（默认 `false` 返回字节完全不变；`true` 时前置对齐的 `行号 | `）。
3. **`agent_loop` 实时定位摘要、二阶段历史压缩增强与超大单文件模块化拆分**
   - [`crates/ziyuan-runtime/src/agent_loop.rs`](../../crates/ziyuan-runtime/src/agent_loop.rs) 与 [`crates/ziyuan-runtime/src/agent_loop/compaction.rs`](../../crates/ziyuan-runtime/src/agent_loop/compaction.rs) 补齐 `read_file` 行区间、批量 `replace_text` 处数及 `staged_diff`／`revert_staged` 的实时定位摘要与二阶段历史压缩记录。
   - 治理超大单文件：将 `agent_loop.rs`（原 2369 行）拆分为 `agent_loop.rs`＋`agent_loop/{compaction,tests}.rs`；将 `tools/temp_cleanup.rs`（原 2718 行）拆分为 `temp_cleanup.rs`＋`temp_cleanup/{sweep,tests}.rs`；将 `tools/symbols.rs`（原 1733 行）拆分为 `symbols.rs`＋`symbols/{rust_jsts,other_langs,tests}.rs`；将暂存自审与回退独立为 `tools/staged.rs`；从 [`crates/ziyuan-web/src/index.html`](../../crates/ziyuan-web/src/index.html) 抽离全局浮层与枢机桥接模块 [`crates/ziyuan-web/src/court-overlays.mjs`](../../crates/ziyuan-web/src/court-overlays.mjs)（附 [`court-overlays.test.mjs`](../../crates/ziyuan-web/src/court-overlays.test.mjs) 单测），并将工具轨迹 `.ok` 配色统一收敛至宋韵五境 `--ok` 语义变量。
4. **版本元数据与文档对齐**
   - 同步更新 [`Cargo.toml`](../../Cargo.toml)、[`Cargo.lock`](../../Cargo.lock)、[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs)（`RELEASES` 序号 84 `1.47.0`）、[`CHANGELOG.md`](../../CHANGELOG.md)、[`README.md`](../../README.md)、[`docs/guide.md`](../guide.md)、[`docs/architecture.md`](../architecture.md)、[`docs/stability.md`](../stability.md)、[`docs/roadmap.md`](../roadmap.md)、[`docs/README.md`](../README.md) 与 [`docs/releasing.md`](../releasing.md)。
