# 1.15.1 验收记录

更新：2026-11-14。1.15.1 已正式发布。本页记录候选检查与发行验收结果，下载包及时间以 [v1.15.1 Release](https://github.com/YuuUehara/Ziyuan/releases/tag/v1.15.1) 为准。

## 本版范围

- 翰林院独立入口、四个工作区与专用启动脚本；保留旧书签和切页时的未保存草稿。
- 工作区显示书名、中文章节和段落位置，内部编号保持不变。增加手工翻译开关、组间导航和送审状态门控，收起编辑器不丢草稿。
- 整本书的状态、草稿、检索与通读复用已校验项目数据，保留保存和送审时的归属、工作区锁及材料基准检查。
- 旧编码文件显示转 UTF-8 的提示；Windows 启动脚本在中文与含空格目录中验证，发行包强制使用 CRLF。
- TXT 可按非空行或空行分段，可在预览时拆分超长段落，归档原件与注音位置保持可核对；命令行支持同一组选项。
- 网页导入允许 24 MiB JSON 请求，原文合计仍限 8 MiB。长预览可折叠展开，分块计算避免反复编码整组原文。
- 成稿导出将同一自然段内相邻的工作段接回，涵盖 TXT、Markdown 与 HTML。
- 整理当前指南与历史文档链接，移除过时内部计划，不包含本地工作计划或构建产物。

## 发行验收

[正式发布流程](https://github.com/YuuUehara/Ziyuan/actions/runs/43587182840) 全部成功：

- Linux x86_64、Intel Mac、Apple 芯片 Mac、Windows x86_64 四个包均构建、上传、重新下载并通过离线验收。
- Release 已公开，四项资产均处于 uploaded 状态。
- 已额外下载公开的 Windows 压缩包，核对两份启动脚本均为有效 UTF-8、CRLF 换行。
- 十一个生产 crate 的 1.15.1 已通过可信发布；实验成员 `ziyuan-sandbox-windows` 不发布。
- 正式发布不包含工作计划、本地测试样本和构建缓存；发布后仅清理已合入主线的分支，保留未合入改动与在用工作树分支。


本次复查发现三类解析警告范围的调整会让旧项目被误判为原文变化，已保留解析版本 1 的持久化范围，并新增三类警告的导入、重开及清单不改写回归检查。Windows 启动脚本另通过缺少程序提示、PowerShell 语法与真实初始化启动检查；测试副本关闭剪贴板与浏览器动作。

## 边界

- 未取得用户的《斜阳》原文件，本次使用自编小说样本验证；不声称已验证该文件。
- 注音或单个完整字形自身超出处理上限时仍会拒绝，并提示调整标记或关闭注音解析，不截断原文。
- 翻译质量须人工把关；本次未增加模型能力或改变准奏规则。
- 四平台发行包须在发布流程中构建、上传、重新下载并验收；crates.io 发布与下载包发布分别核对。
