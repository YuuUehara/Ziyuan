# 1.35.0 验收记录

对应提交：本发布提交（`1.35.0`，含前置特性提交 `30c68d19`、`630f5b41`）。

## 核对项

1. **实时工具执行进度与耗时透明（CLI + TUI + Web，零新事件类型）**
   - [`crates/ziyuan-runtime/src/lib.rs`](../../crates/ziyuan-runtime/src/lib.rs) 与 [`agent_loop.rs`](../../crates/ziyuan-runtime/src/agent_loop.rs)：`ExecutionHooks` 新增向后兼容默认方法 `tool_started(step, tool, summary)` 与 `tool_finished(step, tool, ok, duration_ms)`，为串行与并发只读工具调用记录步序、耗时与安全短定位摘要（绝不泄露文件内容或替换正文）。
   - [`crates/ziyuan-app/src/lib.rs`](../../crates/ziyuan-app/src/lib.rs)、[`crates/ziyuan-cli/src/main.rs`](../../crates/ziyuan-cli/src/main.rs)、[`crates/ziyuan-tui/src/render.rs`](../../crates/ziyuan-tui/src/render.rs) 与 [`crates/ziyuan-web/src/index.html`](../../crates/ziyuan-web/src/index.html)：瞬时 `Progress`/`RunUpdate` 变体不落盘 `court.log`；CLI stderr、TUI 页头／详情与 Web SSE `"tool"` 实时刷新工具状态与耗时。
2. **Windows 原生号舍显式只读工具链快照准入（`ZIYUAN_SANDBOX_TOOLCHAIN`，零宿主 ACL 变更）**
   - [`crates/ziyuan-runtime/src/haoshe.rs`](../../crates/ziyuan-runtime/src/haoshe.rs) 与 [`crates/ziyuan-runtime/src/tools.rs`](../../crates/ziyuan-runtime/src/tools.rs)：新增 `TOOLCHAIN_ENV`、`toolchain_dirs_from_env()` 与 `ShellRunSpec::readonly_toolchains`；Windows AppContainer 下对显式声明的工具链目录执行 fail-closed 路径／重解析点／根目录／敏感目录校验，有界复制到位于 `sandbox_base` 之外的任务私有只读快照，以 `FRFX` 保护 DACL＋低完整性标签准入并前置到容器 `PATH`，任务结束自动清理，零宿主 ACL 变更。
3. **翰林院译书新增韩语、法语、德语及旧编码支持**
   - [`crates/ziyuan-app/src/text_project/model.rs`](../../crates/ziyuan-app/src/text_project/model.rs)、[`store.rs`](../../crates/ziyuan-app/src/text_project/store.rs)、[`crates/ziyuan-cli/src/text_commands.rs`](../../crates/ziyuan-cli/src/text_commands.rs)、[`crates/ziyuan-web/src/text.rs`](../../crates/ziyuan-web/src/text.rs) 与 [`index.html`](../../crates/ziyuan-web/src/index.html)：统一受支持原文语种白名单 `SUPPORTED_SOURCE_LANGUAGES`（`ja`/`en`/`ko`/`fr`/`de` → `zh-CN`），同步更新 CLI、Web API、前端下拉框与跨语种记忆／参考隔离测试。
   - [`crates/ziyuan-app/src/text_project/encoding.rs`](../../crates/ziyuan-app/src/text_project/encoding.rs)、[`import.rs`](../../crates/ziyuan-app/src/text_project/import.rs)、[`tmx.rs`](../../crates/ziyuan-app/src/translation/tmx.rs)、[`srt.rs`](../../crates/ziyuan-app/src/translation/srt.rs)、[`termbase.rs`](../../crates/ziyuan-app/src/translation/materials/termbase.rs)、[`updates.rs`](../../crates/ziyuan-app/src/translation/updates.rs) 与浏览器端 [`continuity.mjs`](../../crates/ziyuan-web/src/continuity.mjs)／[`index.html`](../../crates/ziyuan-web/src/index.html)：扩展 `EUC-KR`／`CP949` 与 `Windows-1252`／`ISO-8859-1` 严格无损解码，贯通 TXT／Markdown／原文更新／SRT／CSV／TBX／TMX 导入，继续严格拒绝 UTF-16 BOM、NUL／控制字节、未定义 C1 字节、GBK 与截断序列。
4. **文档与版本登记**
   - 同步更新 [`Cargo.toml`](../../Cargo.toml)、[`Cargo.lock`](../../Cargo.lock)、[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs)（`RELEASES` 序号 71 `1.35.0`）、[`README.md`](../../README.md)、[`docs/novel-translation.md`](../novel-translation.md)、[`docs/roadmap.md`](../roadmap.md)、[`docs/README.md`](../README.md)、[`docs/releasing.md`](../releasing.md) 与 [`CHANGELOG.md`](../../CHANGELOG.md)。
