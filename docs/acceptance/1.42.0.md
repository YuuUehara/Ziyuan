## 核对项

1. **整书级批量确定性 QA 汇总引擎与 CLI／Web 仪表盘（纯只读，零新增事件与玉玺代码）**
   - [`crates/ziyuan-app/src/translation/verification.rs`](../../crates/ziyuan-app/src/translation/verification.rs)：新增 `ProjectQaReport`、`ProjectQaSummary`、`ProjectQaBlockSummary`、`ProjectQaIssue` 与 `Translations::project_qa_report`；一次性汇总全书各块确定性检查结果、按问题类型分布与段级原文／译文短摘录；未译块单独计入 `untranslated_blocks`，不把 `no_translation` 混入已译块问题明细；已建朝时附带块状态与已定稿计数。
   - [`crates/ziyuan-cli/src/translation_commands.rs`](../../crates/ziyuan-cli/src/translation_commands.rs) 与 [`crates/ziyuan-cli/src/help.rs`](../../crates/ziyuan-cli/src/help.rs)：新增 `ziyuan text qa-report <项目ID> [--json]` 及 shell 补全，覆盖未建朝与 JSON 契约集成测试。
   - [`crates/ziyuan-web/src/text.rs`](../../crates/ziyuan-web/src/text.rs)、[`crates/ziyuan-web/src/translation-workspace.mjs`](../../crates/ziyuan-web/src/translation-workspace.mjs) 与 [`crates/ziyuan-web/src/index.html`](../../crates/ziyuan-web/src/index.html)：新增只读接口 `GET /api/text/{project}/qa-report`（观政可读、零落盘），在「通读交稿」页签落地「整书质检总览」仪表盘（摘要徽章、按问题类型一键筛选、每条问题一键「定位编辑」跳回「译稿」页签并直达对应段落输入框），并在「资料」工具栏提供快捷入口。
2. **段旁实时译文记忆推荐（严格只读、不越项目、不覆盖译稿）**
   - [`crates/ziyuan-app/src/translation/tm.rs`](../../crates/ziyuan-app/src/translation/tm.rs)：新增 `TmSuggestion`、`ParagraphTmSuggestions`、`score_tm_similarity`、`merge_tm_suggestions` 与 `Translations::suggest_tm_for_paragraph`（排除当前段自引用、校验段号与 `limit` 范围 1–10）。
   - [`crates/ziyuan-web/src/text.rs`](../../crates/ziyuan-web/src/text.rs)：新增只读接口 `GET /api/text/{project}/blocks/{block}/tm-suggest?paragraph=<段号>&limit=<1..=10>`（观政可读，拒绝额外查询参数以防跨项目扩权；未建向量索引或未启用 `ZIYUAN_MEMORY_PROVIDER` 时平滑降级为仅返回本地 `tm.json` 命中，已建向量索引时自动融合当前项目定稿命中并去重排序）。
   - [`crates/ziyuan-web/src/human-editor.mjs`](../../crates/ziyuan-web/src/human-editor.mjs) 与 [`crates/ziyuan-web/src/human-editor.test.mjs`](../../crates/ziyuan-web/src/human-editor.test.mjs)：聚焦段落输入框时异步加载只读参考卡（单调请求令牌丢弃过期响应、纯 DOM `textContent` 防 XSS、可选手动「复制参考」，绝不修改译文草稿或脏状态；新增 `focusParagraph` 控制器方法）。
3. **版本登记与文档同步**
