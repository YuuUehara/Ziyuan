## 核对项

1. **`symbol_impact` 符号影响面只读聚合工具（零新增玉玺代码）**
   - [`crates/ziyuan-runtime/src/tools.rs`](../../crates/ziyuan-runtime/src/tools.rs)：随 `Capability::SearchCode` 注册 `symbol_impact`（`is_read_only() == true`），一次汇总符号定义（含起止行号、类型与签名）、按文件分组的调用／引用点（去重上下文行 `context_lines` 0–3、`max_call_sites` 1–100，支持 `path`/`glob`/`kind` 过滤）及汇总统计；跳过注释、字符串与更长标识符子串，暂存改动实时覆盖磁盘并复用 `.ziyuan/index/symbols-v1.json` 增量符号索引与 256 位标识符布隆过滤器。
   - [`crates/ziyuan-runtime/src/agent_loop.rs`](../../crates/ziyuan-runtime/src/agent_loop.rs) 与 [`crates/ziyuan-cli/src/help.rs`](../../crates/ziyuan-cli/src/help.rs)：将 `symbol_impact` 纳入长对话压缩探索摘要与命令行工具说明；[`crates/ziyuan-llm/src/lib.rs`](../../crates/ziyuan-llm/src/lib.rs) 同步更新工具清单断言。
2. **Go／Python／JS 快速静态检查诊断摘录**
   - [`crates/ziyuan-runtime/src/tools/failures.rs`](../../crates/ziyuan-runtime/src/tools/failures.rs)：扩展 `compiler_diagnostic_note`，在 `rustc`/`tsc`/`mypy` 之外新增 `go build`/`go vet`（跳过缩进堆栈）、`ruff`（concise 与默认多行块格式）／`flake8` 与 `eslint`（`stylish` 错误优先、零错误时回退警告）结构化定位摘录；测试成败仍只看退出码。
3. **失败／中断诏令一键续办闭环（CLI + Web + TUI，零新增朝廷事件）**
   - [`crates/ziyuan-app/src/resume_failed.rs`](../../crates/ziyuan-app/src/resume_failed.rs)：新增 `ResumeFailedDraft`、`can_resume_failed_task`、`draft_resume_failed`、`resume_failed_edict_text` 与 `Session::issue_resume_failed`；严格限于失败或已撤销的非译书诏令，沿用原部门与玉玺授权（绝不扩权，盘上已删路径收拢到最近已存在父目录），在 `<前次中断现场 ...>` 隔离围栏内仅附原诏令、失败／撤销原因与最近最多 10 次 `ToolInvoked` 的工具名与成败（绝不带参数或密文）。
   - [`crates/ziyuan-cli`](../../crates/ziyuan-cli/src/args.rs)：新增 `ziyuan edict --resume-failed <ID> [--scope <路径>]... [--queue] [--note <补充指示>] [补充指示]` 及 bash/zsh/fish 补全与契约测试。
   - [`crates/ziyuan-web`](../../crates/ziyuan-web/src/edicts.rs)：`/api/state` 附带 `resume_failed_draft`，新增 `POST /api/tasks/{id}/resume-failed`（观政只读 403，未失败／已结任务 400）及 [`index.html`](../../crates/ziyuan-web/src/index.html) 可折叠续办表单。
   - [`crates/ziyuan-tui`](../../crates/ziyuan-tui/src/input.rs)：诏令页绑定 `C` 键弹出两栏一键续办弹窗（补充指示＋范围）。
4. **版本登记与文档同步**
