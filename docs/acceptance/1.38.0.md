# 1.38.0 验收记录

对应提交：本发布提交（`1.38.0`，含前置特性提交 `742b8efa`）。

## 核对项

1. **Windows 原生号舍 W3 零网络能力命名管道门吏（`ZIYUAN_SANDBOX_ALLOW` 与 MCP `haoshe.network: [...]`）**
   - [`crates/ziyuan-sandbox-windows/src/lib.rs`](../../crates/ziyuan-sandbox-windows/src/lib.rs) 与 [`windows.rs`](../../crates/ziyuan-sandbox-windows/src/windows.rs)：新增全双工重叠 I/O `PipeDoorStream`（支持 `try_clone` 与 `close_write`）、`DoorSpec`、`run_shell_sandboxed_with_door` 与 `spawn_stdio_sandboxed_with_door`；在子进程恢复前于宿主机创建命名管道（`\\.\pipe\ziyuan-door-…`）并附加保护 SDDL `D:P(A;;GA;;;SY)(A;;GA;;;{user})(A;;GRGW;;;{app})S:(ML;;NW;;;LW)`（仅授 `SY`、宿主用户与本任务 AppContainer SID 读写权），在同 SID 0 能力 AppContainer 与同一 `KILL_ON_JOB_CLOSE` Job Object 内拉起纯 `.NET BCL` 异步 TCP↔NamedPipe 桥接（无 cmdlet、无 `Add-Type`、随 Job 排空原子退出），注入 `HTTP_PROXY`／`HTTPS_PROXY`／`ALL_PROXY` 与 `ZIYUAN_HAOSHE_DOOR_PIPE`。工作区根目录维持 `unsafe_code = "forbid"`，零网络 capability、零 loopback 豁免、零宿主防火墙／注册表／ACL 改动。
   - [`crates/ziyuan-runtime/src/haoshe/proxy.rs`](../../crates/ziyuan-runtime/src/haoshe/proxy.rs) 与 [`haoshe.rs`](../../crates/ziyuan-runtime/src/haoshe.rs)：在 Windows 下为 `PipeDoorStream` 实现 `Duplex` 并新增 `start_windows_door` 与 `PipeDoorAudit`；`run_shell`（`run_tests`）与 `spawn_stdio_windows`（长连接 stdio MCP）全面支持 `Network::Only(domains)` 经门吏按域名白名单出站，并记录放行名单与拦下域名；[`crates/ziyuan-cli/src/help.rs`](../../crates/ziyuan-cli/src/help.rs) 同步更新 `ZIYUAN_SANDBOX_ALLOW` 说明。
2. **Windows 原生号舍受控快照子目录可写（MCP `haoshe.write`）与严格 fail-closed 边界**
   - [`crates/ziyuan-sandbox-windows/src/windows.rs`](../../crates/ziyuan-sandbox-windows/src/windows.rs)：`admit_directories` 按目录深度优先准入外层只读父目录再准入内层可写子目录，保证只读项目快照父目录与兄弟目录保持 `FRFX` 只读而嵌套可写子目录独享保护 `FA` 写权。
   - [`crates/ziyuan-runtime/src/haoshe.rs`](../../crates/ziyuan-runtime/src/haoshe.rs) 与 [`mcp.rs`](../../crates/ziyuan-runtime/src/mcp.rs)：`resolve_windows_extra_write_dirs` 严格拒绝空项、绝对路径／盘符／UNC、`~`、`.`/`..`、`.ziyuan`/`.git`/`.jj`/`.env*`/`target`/`node_modules` 及宿主重解析点／非目录文件，仅在任务私有快照内映射可写子目录，宿主项目目录零写入、零 ACL 变更；开放联网（`Network::Open`／MCP `"haoshe": true`）与宿主外部 `CARGO_TARGET_DIR` 继续显式返回 `SandboxUnavailable`。
   - [`crates/ziyuan-sandbox-windows/tests/startup.rs`](../../crates/ziyuan-sandbox-windows/tests/startup.rs)（16/16 原生测试通过）：实测验证嵌套快照只读／可写隔离、本容器 AppContainer 通过命名管道门吏与 `System32\curl.exe` 访问白名单（200）、非白名单遭 403 拦截、直连宿主监听零命中、不同 SID peer AppContainer 遭拒绝访问命名管道与桥接端口，以及 Job 排空后 `active_processes_after == 0`。
3. **文档与版本登记**
   - 同步更新 [`Cargo.toml`](../../Cargo.toml)、[`Cargo.lock`](../../Cargo.lock)、[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs)（`RELEASES` 序号 74 `1.38.0`）、[`docs/adr/0001-windows-sandbox.md`](../adr/0001-windows-sandbox.md)、[`docs/guide.md`](../guide.md)、[`docs/architecture.md`](../architecture.md)、[`docs/roadmap.md`](../roadmap.md)、[`docs/README.md`](../README.md)、[`docs/releasing.md`](../releasing.md) 与 [`CHANGELOG.md`](../../CHANGELOG.md)。
