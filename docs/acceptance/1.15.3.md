# 1.15.3 验收记录

更新：2026-11-14。本页记录 1.15.3 候选发布时的本地验证范围、已检查项与未测边界。

## 本版范围

- **人工译稿送审结构报错与前端校验**：将后端 `submit_human_draft`（以及送审绑定与准奏复用路径）的 `ValidationIssue` 调试列表替换为按章段折叠的中文位置提示（如`第1章 · 第3～14段`），网页端点击「送审当前已保存修订」时在确认弹窗前检查空段并高亮定位首个空白输入框。
- **全仓报错与提示词排查修正**：修正 `TranslationError::DraftConflict`、`MaterialError::Conflict`、确定性检查 `number_mismatch`、CLI `text context diff` / `text status` / `text preview`、译文记忆配对诊断与工作区写锁超时的原始调试/枚举输出；中文化资料模型 `mirrorError` 并补充 Web `api()` 非 JSON 响应中文兜底。
- **版本登记**：工作区 crate、依赖、`Cargo.lock` 及 `ziyuan-storage::RELEASES` 登记 `1.15.3`，不新增事件类型，不提高旧事件簿读取门槛。
