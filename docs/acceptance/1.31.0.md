# 1.31.0 验收记录

对应提交：本发布提交（`1.31.0`）。

## 核对项

1. **Windows 原生号舍 W2 正式接入生产（`ziyuan-runtime` + `ziyuan-sandbox-windows`）**
   - **治理与 crates.io 首发闭环**：唯一维护者（`YuuUehara`）完成维护者审阅与长期维护确认；`ziyuan-sandbox-windows` 已在 crates.io 完成首个版本（`1.30.0`）手工发布与 Trusted Publishing（`release.yml`）配置，并排入 `.github/workflows/release.yml` 十二个生产 crate 发布顺序（位于 `ziyuan-runtime` 之前）。
   - **零 `unsafe` 生产接入**：[`crates/ziyuan-runtime/Cargo.toml`](../../crates/ziyuan-runtime/Cargo.toml) 新增 `[target.'cfg(windows)'.dependencies] ziyuan-sandbox-windows.workspace = true`，工作区根目录与 `ziyuan-runtime` 均保持 `unsafe_code = "forbid"`。
   - **受控执行切换（[`crates/ziyuan-runtime/src/haoshe.rs`](../../crates/ziyuan-runtime/src/haoshe.rs)）**：
     - `run_shell` 在 Windows `Mode::Auto`／`Mode::Require` 下经 `windows_sandbox_available()` 核验 `FileSystemAndNetworkIsolated` 后调用 `ziyuan_sandbox_windows::run_shell_sandboxed`（0 能力 `AppContainerChildCapable`＋`PrivateDesktop`＋`KILL_ON_JOB_CLOSE` Job Object）；
     - 过滤 12 项宿主系统／用户目录保留变量，由沙箱统一注入 `SystemRoot` 派生值与任务私有 `USERPROFILE`/`HOME`/`APPDATA`/`LOCALAPPDATA`/`TEMP`/`TMP`；
     - 按 `max_output.max(max_failure_scan)` 有界采集尾部输出并区分 `tail` 与 `failure_scan` 窗口，透传主动取消信号，并在 `haoshe_note` 如实标注 `号舍（Windows AppContainer＋Job）` 与清理诊断；
     - 继续对 `Network::Only`/`Open`、外部 `CARGO_TARGET_DIR` 与长连接 stdio 外藩（[`crates/ziyuan-runtime/src/mcp.rs`](../../crates/ziyuan-runtime/src/mcp.rs)）显式 fail closed（`SandboxUnavailable`）。
   - **原生 Windows 11 实测**：
     - `haoshe::tests::run_shell_windows_appcontainer_isolates_copy_blocks_host_and_honors_policies` 通过（验证 `Network::Only` 与外部 `CARGO_TARGET_DIR` 拒绝、AppContainer 副本可写＋宿主秘密文件不可读＋12 项保留变量过滤、取消即时终止 Job、以及 `tail` 截断与 `failure_scan` 保留）；
     - `tools::tests::writes_are_staged_tested_in_a_copy_and_applied_only_without_conflicts` 与 `tools::tests::run_tests_keeps_cargo_failure_names_when_the_assertion_is_not_in_the_tail` 在清除 `CARGO_TARGET_DIR` 后经 `RunTests` 端到端实跑原生 Windows AppContainer 通过，同时保留外部 `CARGO_TARGET_DIR` 拒绝用例。

2. **CI、版本与文档同步**
   - [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml)：Windows CI 作业名称与说明更新为原生号舍（AppContainer＋Job）实测。
   - 登记版本 `1.31.0`（[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs) `RELEASES` 序号 65，零新增事件与玉玺代码）。
   - 同步更新 [ADR-0001](../adr/0001-windows-sandbox.md)、[SECURITY.md](../../SECURITY.md)、[README.md](../../README.md)、[体系结构](../architecture.md)、[稳定性约定](../stability.md)、[路线图](../roadmap.md)、[发布指南](../releasing.md) 与 [CHANGELOG.md](../../CHANGELOG.md)。
