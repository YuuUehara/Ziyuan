# 1.15.5 验收记录

更新：2026-11-19。本页记录 1.15.5 候选发布时的本地验证范围、已检查项与未测边界。

## 本版范围

- **说明与发行记录**：1.15.0 的变更说明和验收页改为标签 `v1.15.0`（`ac67b034`）已于 2026-11-13 公开，附四个平台包。准备生产资料后的下一步改到资料工具栏的「批准上下文」。
- **确定性检查与译文记忆**：网页筛选只保留 `text qa` 实际会返回的类型，去掉不会出现的「人物名」。未关联人物时这道检查只看独立术语。网页和命令行的记忆说明改为 `local`、`deterministic`，以及须先授权的 `remote`。
- **命令行**：shell 补全补上现有 `text` 子命令。`source-update`、`read`、`preflight`、`search`、`draft-replace`、`issue`、`backup`、`restore` 和 `tmx preview`／`import` 默认打印中文摘要；加 `--json` 才输出完整 JSON。`tmx export` 不指定文件时仍输出 TMX 正文。
- **版本登记**：工作区 crate、依赖、`Cargo.lock` 与 `ziyuan-storage::RELEASES` 登记 `1.15.5`，不新增事件类型，不提高旧事件簿读取门槛。
