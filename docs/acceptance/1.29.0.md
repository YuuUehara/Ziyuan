# 1.29.0 验收记录

对应提交：本发布提交（`1.29.0`）。

## 核对项

1. **Windows 原生号舍 W2 `AppContainerChildCapable` 隔离实测与 `run_shell_sandboxed`（`ziyuan-sandbox-windows`）**
   - [`crates/ziyuan-sandbox-windows/src/lib.rs`](../../crates/ziyuan-sandbox-windows/src/lib.rs) 与 [`crates/ziyuan-sandbox-windows/src/windows.rs`](../../crates/ziyuan-sandbox-windows/src/windows.rs)：
     - 新增 `SandboxMode`（`StrictLpac` 默认、`AppContainerChildCapable` 零能力 AppContainer + `KILL_ON_JOB_CLOSE` Job）与 `run_sandboxed_with_mode`；
     - 新增 `ShellSpec` 与 `run_shell_sandboxed`，通过 `%SystemRoot%\System32\cmd.exe /D /S /C "<command>"`（`/D` 禁用注册表 AutoRun，拒绝 NUL/CR/LF 及重解析点）在任务独立零能力 AppContainer + Job 内运行 shell 命令并收尾整棵后代进程树。
   - 原生非管理员 Windows 11（`HOST_ELEVATED=0`）实测（`cargo test -p ziyuan-sandbox-windows --locked -- --nocapture`，10/10 通过）：
     - `w2_appcontainer_child_capable_preserves_file_and_network_isolation`：在 `AAP_ACCESS=1`、`TokenCapabilities=0` 下通过完整 W1b 文件隔离矩阵（任务副本读写成功，宿主源码、`.ziyuan`、模拟 `.ssh`、`.git` 与 peer 目录读写全部返回 Win32 `ERROR_ACCESS_DENIED (5)`）与 W1c 零网络隔离矩阵（`NET_CAPS=0`，IPv4 TCP/IPv6 TCP 回环与 IPv4 UDP 经 WFP 阻断，三类宿主监听确认 `HOST_NET_ZERO_HITS=1`）；
     - `w2_run_shell_sandboxed_spawns_children_isolates_host_and_drains_on_timeout_and_cancel`：`cmd.exe /D /S /C` 可写入任务副本并派生子进程（子进程核验 `APP=1 AAP_ACCESS=1 JOB=1 CAPS=0 CLEAN_ENV=1`），读取与改写宿主秘密文件均遭拒绝（`拒绝访问`），超时与主动取消均由 `TerminateJobObject` 干净清空后代（`active_processes_after == 0`、`cleanup_warnings == []`）。

2. **运行时 W2 执行所有权边界重构（`ziyuan-runtime::haoshe` + `RunTests`）**
   - 按 [ADR-0001](../adr/0001-windows-sandbox.md) §平台边界 #2，[`crates/ziyuan-runtime/src/haoshe.rs`](../../crates/ziyuan-runtime/src/haoshe.rs) 新增拥有完整生命周期的 `ShellRunSpec`、`ShellRunOutput` 与 `run_shell`，统一接管沙箱构造、门吏代理、环境变量过滤、超时终止与输出／失败扫描窗口采集；[`crates/ziyuan-runtime/src/tools.rs`](../../crates/ziyuan-runtime/src/tools.rs) 的 `RunTests::run_in_copy` 已切换为直接委托 `haoshe::run_shell`，不再在工具层直接操作裸 `Command`/`Child`。
   - Windows 上 `mode != Mode::Off` 继续保持方案 A 失败关闭（返回稳定错误 `SandboxUnavailable`），并按 ADR-0001 显式前置校验并拒绝 `Network::Only`/`Open`（仅支持全断网）与外部 `CARGO_TARGET_DIR` 等 `extra_writable` 目录。
   - 根工作区与 `ziyuan-runtime` 保持 `unsafe_code = "forbid"`，不依赖未发布的 `ziyuan-sandbox-windows`（保证 crates.io 正常发版）。
