# 1.4.0 验收记录

## 范围与结论

本版交付原文预览／注音、成稿导出、显式参考、词证与逐段勘校、逐阶段用量账本及重复读取材料精简。沿用词义核对、朱批复核、双路审校与人工分批，不自动推进下一块，不增加或绕过御览门槛。

本记录建立时，功能提交及跨平台修复已推送；版本登记为 1.4.0，版本提交 CI 与正式发行包尚待验收。不能把功能 CI 通过当作正式发行完成。

## 升级与隐私

- 新写入文本项目使用 schema 2，新程序仍读取旧 schema 1；旧 1.3 无法读取 schema 2。
- 参考绑定事件 `TRANSREFS` 最低读取版本为 1.4.0。旧事件编码不变，旧程序不得继续读含新事件的事件簿。
- 所选参考的原译文会持久保存在 `court.log`，不是可删的记忆缓存。分享或备份前须核对隐私及作品权利。
- 用量只涵盖已报告事件；未知不是零，估价不是账单，不同币种不相加。请求字节减少不证明 token、延迟、费用或文学质量改善。

## 正式发行核对

待版本提交 CI 通过后，推送 `v1.4.0`，由 Release 工作流构建四种原生包、重新下载并执行验收后公开。之后独立核对十一个 crate 的发布结果，尤其本版首次实际验证 `ziyuan-memory` 的可信自动发布。当前不提前宣称下载包或注册表已可用。

## 未验证范围与下一步

本轮没有新增付费小说复验、专家终审或生产费用对照。已有小样发现用于形成词证、勘校和账本功能，不能据工程测试宣称误译已普遍解决。保留人工争议处理与批次验收，不自动扩大文学试验。

1.4 发布收尾后，开发重心转回代码任务侧：先盘点代码任务的派工、工具授权、测试回报与差异准奏闭环，再据可复现问题安排下一批；不在本次发布夹带新功能或继续扩大翻译范围。
