# 1.13.0 验收记录（开发中，未发布）

日期：2026-11-09。包版本仍为 1.12.0；本页只记录开发版实际做过的检查，不表示已发布、已做原生 CI 或已通过文学质量评估。

## 本批范围

- 三态自动快照：保存人工草稿、准奏、定稿后自动写 `draft`／`approved`／`finalized` 快照；同状态同内容不重复。新增 `ziyuan text version list|save|compare|compare-draft|prune`。
- 版本对比：现行译稿与快照、人工草稿与快照逐段比较，区分新增、删除、改写与标记变化。
- 版本清理：自动快照每状态保留最新 3 份；`version prune` 默认预览、`--yes` 才删，手工快照默认保留。
- DOCX／EPUB：导入不再拒绝粗体、斜体、表格与图片；导入成功后保留原件；`export-docx`／`export-epub` 在成稿资格检查后用现行译稿回填文字，保留原有 run 标记、表格与图片。
- 术语表：CSV／TBX 增加类别、范围、可用起点、读音、证据、关联术语、声线、称谓规则；旧八列 CSV 仍可读。
- Web：译书卡片新增「译稿版本」面板（列表、对比、保存、清理）；本地资料文案与批准入口对齐。

## CI 修正

提交 `247b904` 的 CI 有两处失败，均已在本批修正：

- `fmt · clippy · 测试 · smoke` 停在 `cargo fmt --all -- --check`：本批先前的提交留下了未格式化文件，现已全仓 `cargo fmt`；1.99.1 与 1.90 的 rustfmt 均通过。
- `依赖审计` 失败：`cargo audit` 报 `zip` 2.6.1（RUSTSEC-2026-0367／0368／0369／0429）与 `quick-xml` 0.37.5（RUSTSEC-2026-0194／0195）。已将 `zip` 升至 9.4.2（DOCX／EPUB 读写改用其 `name()` 返回 `Result` 的 API）、`quick-xml` 升至 0.41（文字用 `xml_content`、属性用 `normalized_value`）；`cargo audit` 现退出码 0，只剩 `bincode` 未维护警告（不阻断）。`zip` 升级后 DOCX／EPUB 导入与回填测试仍通过。
- Windows 上 `mcp::tests::http_servers_speak_streamable_http` 曾在全量测试中偶发清理失败（子进程句柄晚释放）。测试清理改为短暂重试；单测与全量测试复跑通过，产品代码未改。

## 未验证与边界

- 没有用真实作者提供的 DOCX／EPUB 做完整往返；复杂分页、脚注、浮动对象、样式继承与阅读器兼容未验收。
- 回填按文字节点长度比例分配译文，是保留标记范围的近似，不保证与人工排版逐字一致；DOCX 嵌套段落、EPUB `script`／`style` 文字明确不处理。
- 版本快照是本地辅助材料，不是批准、导出或文学质量凭据；清理永久删除，删除后不能从事件簿重建正文。
- 未做原生 Windows／macOS CI，也未验证旧二进制读取本批新文件；本批不新增事件类型、不提高最低读取版本。
- Web 版本面板已用本机 Chrome 检查列表、对比与 1440／390 CSS px 布局；三套主题、真实输入法、其它浏览器与桌面系统未验收。
- 截图未使用任何真实作品：演示项目为自编样章，只说明界面，不是文学质量或真实文件样本。
