# 1.14.1 验收记录

更新：2026-11-13。本页记录 1.14.1 的文案、入口和排版检查。上游准备记录与本轮复验分别列出；1.14.0 的功能与发行结果见 [1.14.0 验收记录](1.14.0.md)。候选检查通过不代表已经公开下载包。

## 本版范围

- 网页「章节导出」增加 HTML。应用层 `ExportFormat::Html` 与 `GET /api/text/{id}/export?format=html` 在 1.14.0 已能导出成稿；HTML 保留注音、着重、粗斜体及同范围叠加样式。本版只补页面选项，不改导出规则。
- 网页取回原件不沿用定稿格式与编排，固定请求 `format=txt`、`layout=chapters`。接口行为不变：原件带上其他格式或编排仍拒绝。
- 文本项目指南改为 `--format txt|md|html`，并写明逐章／全书的 `.html`。着重号和同一范围叠加的标记仍不能用 Markdown 导出，须用 HTML；TXT 遇带标记稿仍整批拒绝。
- `ziyuan text help` 写明 TAR 可含 HTML 定稿，并列出已有的 `search`、`draft-replace`、`tmx`。
- 使用指南说明 `work/`、`codex/` 书签与常规 CI 的对应关系，以及合并后同步、忘掉已删除远端书签的命令。
- 工作区版本、锁文件里的内部包版本，以及发布版本表升到 1.14.1。版本表只追加登记，不提高旧事件簿的最低读取版本。不新增事件，不改冻结命令的含义。
- 当前指南和前端统一“页面暂存、草稿、准奏、定稿”等用语，用操作说明解释朝廷称呼；资料预览的内部标签改为中文，并修正“4A 尚未发版”等过时状态。
- 表单空间不足时自动换行，修复窄屏下“全书”、格式和荐举官职选项被挤掉文字的问题，保留三套配色、衬线标题与细边框。

## 边界

- 页面检查使用自编数据，不覆盖全部浏览器、输入法或所有动态资料组合。
- HTML 成稿不承诺照搬 DOCX／EPUB 的分页、脚注或浮动对象。
- Markdown 仍整批拒绝着重号和同一范围互相重叠的标记。
- 不改审批、权限、事件格式或外发规则。原件导出的拒绝规则也不放宽。
