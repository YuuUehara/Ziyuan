# 1.15.2 验收记录

更新：2026-11-14。本页记录 1.15.2 候选发布时的本地验证范围、已检查项与未测边界。

## 本版范围

- **手工翻译优先的工作台调整**：在「翰林院 → 译稿」默认开启独立的「手工翻译」开关并置顶双语编辑器、多章汇总进度与组间导航；将「三栏对照、逐段朱批与模型译校」收为默认折叠抽屉，关闭「手工翻译」时自动展开；「段旁提示」置于编辑器与对照抽屉之间，「全文检索与草稿替换」及「逐段勘校」默认折叠置底并统一标题与间距；点击检索结果支持跳转编辑段或自动展开对应对照视图。
- **文档合并与截图刷新**：将原 `docs/text-projects.md`、`docs/translation-continuity.md` 与 `docs/novel-translation.md` 合并为[翰林院译书指南](../novel-translation.md)，保留既有章节锚点并同步更新 `README.md`、`CHANGELOG.md`、`docs/README.md`、`docs/guide.md`、`docs/memory.md`、`docs/subscriptions.md`、`docs/architecture.md`、`docs/stability.md` 及历史验收文档中的对应链接。
- **界面截图与旧资源清理**：基于当前版本界面与虚构自写示例《霧灯りの小駅》刷新并补充 10 张 Web 截图（覆盖奉天门、观政只读、翰林院「译稿 / 模型 / 资料 / 通读交稿」、TXT 导入与译文记忆的桌面/窄屏视图），删除过时文档与 3 张早期截图。
- **版本登记**：工作区 crate、依赖及 `ziyuan-storage::RELEASES` 登记 `1.15.2`，不新增事件类型，不提高旧事件簿读取门槛。
