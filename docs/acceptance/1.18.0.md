# 1.18.0 验收记录

更新：2026-11-20。本页记录发版提交写入前在本机已执行的检查。标签 `v1.18.0`、四平台发行包及 crates.io 自动发布要等标签推送后由 CI 完成，这里不提前写成已完成。

## 本版范围

- 轻量代码符号工具（零外部依赖、零事件簿兼容变更）：
  - 新增 `file_outline`（随 `read_file` 授予）：提取单个 Rust／JavaScript／TypeScript／Python／Go／C／C++／Markdown 文件的符号大纲、所属容器（`impl`／`trait`／`class`／`namespace`）与行号，支持 `kind` 过滤与 `offset`/`limit` 翻页。
  - 新增 `find_symbols`（随 `search_code` 授予）：跨文件按符号名查找定义，跳过注释（含 Rust 嵌套块注释）、原始／多行字符串与 Markdown 代码块，支持 `path`、`kind`、`exact`、`ignore_case`、`offset`、`limit`。
  - 两者均先按玉玺范围与禁区（`.ziyuan`、`.git`、`.jj`、`.env*`）过滤，跳过 `target` 与 `node_modules`，不追踪符号链接，并优先读取本次任务已暂存的修改与新建文件。
- 多测试框架失败摘录：
  - 修复 `cargo test` 在 Rust 1.89+ 输出带线程 ID（`thread 'name' (12345) panicked at`）时断言摘录缺失的问题。
  - 扩展 `run_tests` 失败摘录至 `pytest`、`node --test`（spec 与 TAP 格式）、`go test` 与 `jest`/`vitest`；未识别格式仍仅返回输出末尾，测试成败与都察院核验仍以退出码为准。
- 文档同步：更新[使用指南](../guide.md)、[路线图](../roadmap.md)（补齐 1.16.1、1.17.0 与 1.18.0 里程碑）及命令行帮助。
- 工作区 crate、依赖、`Cargo.lock` 与 `ziyuan-storage::RELEASES` 登记 `1.18.0`。不新增朝廷事件类型，不提高旧事件簿读取门槛。
