# 1.19.0 验收记录

- 核对日期：2026-11-20
- 验收范围：Windows 原生号舍独立实验 crate（`ziyuan-sandbox-windows`）W1b 边界、W1c 网络阻断、W1d 生命周期与 W2 就绪安全 Rust 接口；同步修复 1.18.0 Python 嵌套局部 `def` 提取与 `reference_execution` 工具列表断言。
- 平台：本机 Windows 11 x86_64 MSVC（非管理员桌面用户 `HOST_ELEVATED=0`）。

## 实际执行检查

1. **格式、静态检查与全特性编译**：
   - `cargo fmt --all -- --check`：通过
   - `cargo clippy --workspace --all-targets --locked -- -D warnings`：通过（0 警告）
   - `cargo check --workspace --all-targets --all-features --locked`：通过
2. **Windows 原生号舍隔离实测（`cargo test -p ziyuan-sandbox-windows --locked -- --nocapture`）**：8 / 8 通过
   - W1a：普通 AppContainer vs 严格 LPAC（`AAP_ACCESS=0`）、句柄白名单排除未选哨兵句柄、恢复前注入故障零字节输出且清理 profile。
   - W1b：任务私有读写、宿主与 peer 哨兵拒绝（Win32 `5`）、只读依赖目录（保护 DACL＋低完整性 `S-1-16-4096`＋`FileIdInfo` 句柄身份核验）、大小写变体拒绝（`SOURCE.RS`、`.GIT/CONFIG`）、Unicode＋空格私有路径、`>=160` 字符嵌套路径读写，以及 NTFS 目录联接（`mklink /J`）重解析点拒绝（`PermissionDenied`）。
   - W1c：本机 IPv4 TCP、IPv4 UDP、IPv6 TCP 回环监听先过宿主正向对照后归零；LPAC 子进程核验 `TokenCapabilities == 0`、Windows 11 内核拒绝 `WSAStartup`（`WSASYSCALLFAILURE` 10107），且三类宿主监听确认零连接／零数据包抵达（`HOST_NET_ZERO_HITS=1`）。
   - W1d 与安全 API：`probe_capability()` 返回 `FileSystemAndNetworkIsolated`；三路并行 `run_sandboxed` 互不干扰；严格 LPAC 超时与主动取消均确认 `ActiveProcesses == 0` 且零清理警告；保留环境变量覆盖拒绝；普通 0 能力 AppContainer＋`KILL_ON_JOB_CLOSE` Job 下超时、主动取消与父退孙留（孙进程持有继承 stdout）均由 `TerminateJobObject`＋进程数归零干净收尾。
3. **全工作区与前端单测**：
   - `cargo test --workspace --locked --no-fail-fast`：全部工作区单元与集成测试通过（含 `ziyuan-runtime` 129/129、`ziyuan-cli` `reference_execution` 与 `usage`、`ziyuan-web` 76/76、`ziyuan-tui` 14/14、`ziyuan-sandbox-windows` 8/8 等）。
