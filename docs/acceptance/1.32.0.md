# 1.32.0 验收记录

对应提交：本发布提交（`1.32.0`，含前置特性提交 `1e722d2f`）。

## 核对项

1. **`run_tests` 主动取消传播（撤销 / 超时 / 度支停支）**
   - [`crates/ziyuan-runtime/src/lib.rs`](../../crates/ziyuan-runtime/src/lib.rs)：`ExecutionHooks` 新增向后兼容默认方法 `cancel_flag(&self) -> Option<Arc<AtomicBool>>`。
   - [`crates/ziyuan-runtime/src/scheduler.rs`](../../crates/ziyuan-runtime/src/scheduler.rs)：`CancelToken` 同步维护 `Arc<AtomicBool>` 并提供 `flag()`，`TaskHooks::cancel_flag()` 将手动撤销、单任务超时与度支停支信号透传给执行层。
   - [`crates/ziyuan-runtime/src/agent_loop.rs`](../../crates/ziyuan-runtime/src/agent_loop.rs)：`Tool` 新增向后兼容默认方法 `execute_with_cancel`，`Metered` 透传 `cancel_flag()` 并在顺序与并发工具调用路径传递至工具实现。
   - [`crates/ziyuan-runtime/src/tools.rs`](../../crates/ziyuan-runtime/src/tools.rs)：`RunTests` 覆写 `execute_with_cancel`，启动前先核查撤销标志（已撤销直接跳过工作区复制），运行中将 `cancel` 透传至 `haoshe::ShellRunSpec::cancel`，覆盖 Unix、普通命令及 Windows 原生 AppContainer＋Job 进程树即时终止。
2. **`replace_text` 行范围锚定与失配／歧义诊断**
   - [`crates/ziyuan-runtime/src/tools.rs`](../../crates/ziyuan-runtime/src/tools.rs)：`ReplaceText` 在单处替换与批量 `edits[]` 均支持可选 1 起始含首尾 `start_line` / `end_line` 参数（严格范围校验，禁止 `edits` 与顶层 `start_line`/`end_line` 混传，保持精确唯一替换、不做模糊替换）。
   - 多处匹配时报错附带具体 1 起始行号与 `start_line`/`end_line` 消歧建议；找不到时若指定行范围外存在完全匹配则直接给出实际行号，否则给出最接近的 Top-3 候选行号与代码摘录。
3. **长对话二阶段可控历史压缩**
   - [`crates/ziyuan-runtime/src/agent_loop.rs`](../../crates/ziyuan-runtime/src/agent_loop.rs)：新增 `compact_turns`，在现有 `abridge` 仍超 `context_tokens` 且积累不少于 6 轮完整对话时确定性（不调用模型）将最早的完整轮次折叠为单条带外来文书围栏的结构化工作摘要（保留已暂存修改、近期 `run_tests` 诊断与查阅足迹，完整保留最近 4 轮），严守 `CallPrelude`/`ToolCall`/`ToolOutput` 配对与角色交替协议，同步重映射 `read_file` 去重索引并重置 `Metered` 用量基线。
4. **文档与版本登记**
   - 同步更新 [`docs/guide.md`](../guide.md)、[`docs/architecture.md`](../architecture.md)、[`docs/roadmap.md`](../roadmap.md)、[`docs/README.md`](../README.md)、[`docs/releasing.md`](../releasing.md) 与 [`CHANGELOG.md`](../../CHANGELOG.md)。
   - 登记次版本 `1.32.0`（[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs) `RELEASES` 序号 68，零新增事件与玉玺代码，不提高旧事件簿读取门槛）。
