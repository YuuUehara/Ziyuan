# 1.47.1 验收记录

对应提交：本发布提交（`1.47.1`）。

## 核对项

1. **`Capability::WriteFile` 工具集合集成测试对齐**
   - [`crates/ziyuan-cli/tests/reference_execution.rs`](../../crates/ziyuan-cli/tests/reference_execution.rs) 更新 `assert_writer_tools` 中 `WriteFile` 授权工具列表断言，补入 `1.47.0` 随 `write_file` 授予的 `staged_diff` 与 `revert_staged`，确保选定参考与无参考对照两条真实 HTTP 执行链路均校验完整 13 项工具集合。
2. **都察院验功失效规则补入 `revert_staged`**
   - [`crates/ziyuan-app/src/censorate.rs`](../../crates/ziyuan-app/src/censorate.rs) 将 `revert_staged` 纳入 `is_write_tool`（在 `run_tests` 通过后若再执行成功的 `revert_staged`，先前测试记录自动标为失效须重验；只读 `staged_diff` 不影响验功有效性），并同步更新都察院复核系统提示。
   - [`crates/ziyuan-app/src/tests.rs`](../../crates/ziyuan-app/src/tests.rs) 新增 `staged_diff_preserves_and_revert_staged_invalidates_test_evidence` 单测。
3. **版本登记与文档同步**
   - 因 `v1.47.0` 已在 GitHub Releases 与 crates.io 公开发布，按 [`docs/releasing.md`](../releasing.md) 不覆盖已公开标签的约定，升修订号为 `1.47.1`（[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs) `RELEASES` 序号 85），同步更新 [`Cargo.toml`](../../Cargo.toml)、[`Cargo.lock`](../../Cargo.lock)、[`CHANGELOG.md`](../../CHANGELOG.md)、[`docs/README.md`](../README.md)、[`docs/releasing.md`](../releasing.md)、[`docs/roadmap.md`](../roadmap.md) 与 [`docs/stability.md`](../stability.md)。
