# 1.27.0 验收记录

本版加深工部代码搜索与导航能力：在不新增朝廷事件与玉玺代码的前提下，为 `list_files` 增加 `glob` 路径过滤，为 `search_code` 增加 `regex`、`glob`、`context_lines`（0–5）及暂存新建文件覆盖，并随 `Capability::SearchCode` 新增跨文件整词引用查找工具 `find_references`。

## 验收项

1. **受控路径 glob 匹配器（`crates/ziyuan-runtime/src/tools/glob.rs`）**
   - 将 glob 编译为受容量限制的线性时间正则（`regex::RegexBuilder`，无回溯放大），支持 `*`、`?`、`**`（跨零或多层目录）、`[abc]`／`[!a-z]` 与 `{rs,toml}` 多选；不含 `/` 时按文件名匹配，含 `/` 时按 `/` 归一化相对路径全匹配；拒绝空模式、超长模式或未闭合括号。
   - `list_files` 新增可选 `glob` 参数，同时过滤磁盘文件与暂存新建文件；不传 `glob` 时完全保持既有输出格式。
2. **`search_code` 增强与暂存新建文件覆盖**
   - 新增可选参数 `regex`（Rust 线性时间正则，受 `size_limit(1 << 20)` 保护）、`glob` 与 `context_lines`（0–5，匹配行用 `:`、上下邻行用 `-`、块间以 `---` 分隔）。
   - 同时覆盖磁盘文件、暂存修改与暂存新建文件（跳过暂存删除与构建产物）；省略全部新参数时 100% 保持原字面量检索格式。
3. **跨文件引用查找工具 `find_references`**
   - 随 `Capability::SearchCode` 授予（玉玺编码不变）；按整词标识符边界匹配，借助 `symbols::strip_code_lines` 剔除行／块注释、字符串、原始字符串与 Python 三引号 docstring，并以空格占位避免两侧标识符黏连。
   - 借助 `symbols::extract_for_path` 自动区分 `[定义]` 与 `[引用]`，支持 `path`、`glob`、`include_definitions`（默认 `true`）、`offset` 与 `limit`（1–50）；严守玉玺范围与 `.ziyuan`／`.git`／`.jj`／`.env*` 禁区。
4. **自动化验证**
   - `cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets --locked -- -D warnings`、`cargo check --workspace --all-targets --all-features --locked`。
   - `cargo test --workspace --locked`（含 `glob` 单元测试、`list_files_and_search_code_support_glob_regex_context_and_staged_new_files`、`find_references_skips_comments_strings_and_substrings_and_respects_scope_and_staged` 及 `ziyuan-llm` 工具清单测试）。
   - `node --test crates/ziyuan-web/src/*.test.mjs` 与 `python scripts/check-doc-links.py` 全部通过。
