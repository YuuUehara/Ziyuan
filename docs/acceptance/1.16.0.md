# 1.16.0 验收记录

更新：2026-11-19。本页是 1.16.0 候选的范围和本地检查，不是已发布版本。版本号仍是 `1.15.5`，变更记在 CHANGELOG 的未发布一节。不打标签，不发版。

## 本版范围

- `read_file` 可按行窗口读：`offset` 从第 1 行起，`lines` 为行数。返回里写明总行数，以及后面还有没有。不带这两个参数时，仍从文件开头读，超过 64 KiB 截断。越出玉玺或禁区仍拒绝。
- 授了 `write_file` 就有 `replace_text`。它只替换文件里恰好出现一次的旧文本；找不到或多处就拒绝，不做模糊匹配，不删除文件，也不改名。结果进原来的暂存和逐段准奏。不另设玉玺代码。
- `search_code` 可限定目录、忽略大小写，并用 `offset`／`limit` 翻页，一页最多 50 条。先按授权范围和禁区过滤，不搜 `target`、`node_modules`。不带新参数时仍是区分大小写的前 50 条。没有符号索引。
- `run_tests` 仍只跑皇帝设定的 `ZIYUAN_TEST_COMMAND`，仍入号舍。认得出 `cargo test` 的失败名单时，另附失败测试名和断言摘录（从日志末尾最多回看 1 MiB）。其他输出仍只给末尾 8 KiB。都察院仍按这次调用成功或失败来核验。
- 终端下诏可以选部门、查阅范围和工具。留空范围是整个项目，留空工具是只读玉玺。校验与命令行相同。
- 不新增朝廷事件，不改已有命令和事件字段的含义。Windows 实验号舍未接入。

## 边界

- 行窗口只对 UTF-8 文本给出行号；不是文本时拒绝按行读。不带行窗口的旧读法不变。
- `replace_text` 按字面量、不重叠地计数。空的 `old`、新旧相同、结果超过 256 KiB，都会拒绝或不动暂存。
- 搜索分页按「含有这段字的行」计数，不是同一行里的多次出现。忽略大小写用 Unicode 小写，不折叠全角或相似字形。
- `cargo test` 的摘录认的是 `test result: FAILED` 和后面的失败名单，以及 `thread '…' panicked at`。编译失败、pytest 等其他输出不另做解析。摘录看不到日志末尾 1 MiB 以前的断言。
- 终端下诏不授外藩 MCP。要授 MCP 仍用命令行或网页。
- 没有放开 shell，没有符号索引，没有并行写的工作副本隔离，也没有把 Windows 号舍接到生产路径。
- 提交 `0e81c935` 的六个 GitHub CI 作业已通过：fmt／clippy／测试／smoke、依赖审计、Rust 1.89、Linux glibc 2.35、macOS 号舍、Windows 功能可用且号舍失败关闭。其后的补丁不记在这次结果里。
