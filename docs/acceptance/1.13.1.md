# 1.13.1 验收记录

## 本批范围

- Web 新建项目：译书页可直接创建空项目，再走既有「导入原文」预览／确认流程；不再要求先运行 `ziyuan text init`／`import`。
- 创建项目要求标题、原文语言、来源与权利声明；来源与权利仍只是自述，不作核验；观政仍只读。
- 文案：新建项目弹窗、空状态、导入提示与版本面板按现有页面文风收紧，去掉冗长说明句。
- 不改变 CLI、批准、权限、外发边界、译稿与事件簿格式。
