# 1.33.0 验收记录

对应提交：本发布提交（`1.33.0`，含前置特性提交 `b765c3e9`）。

## 核对项

1. **符号起止行号与 `read_file` 可选 `end_line`**
   - [`crates/ziyuan-runtime/src/tools/symbols.rs`](../../crates/ziyuan-runtime/src/tools/symbols.rs)：`Symbol` 新增 `end_line` 与 `line_span()`（单行 `42`、跨行 `42-98`），覆盖 Rust、JS/TS、Python、Go、C/C++、Markdown 全部 6 类语言提取器（含跨行签名、原始字符串常量、Python docstring、C/C++ 续行宏、Allman 风格与 Markdown 父子标题裁剪）。
   - [`crates/ziyuan-runtime/src/tools.rs`](../../crates/ziyuan-runtime/src/tools.rs)：`file_outline` 与 `find_symbols` 展示起止行号；`read_file` 新增可选 `end_line` 参数（1 起始含首尾，与 `lines` 互斥并校验边界），可直接复用符号行号范围。
2. **已落盘诏令安全回滚（CLI + Web + 应用层，零新事件类型）**
   - [`crates/ziyuan-app/src/edicts.rs`](../../crates/ziyuan-app/src/edicts.rs) 与 [`crates/ziyuan-app/src/lib.rs`](../../crates/ziyuan-app/src/lib.rs)：新增 `RevertAction`、`RevertStatus`、`RevertFilePreview`、`RevertReport`、`preview_revert_for`、`Session::preview_revert` 与 `Session::revert_changes`。按 `selected_files` 仅回滚实际落盘部分（尊重 `--skip`），在工作区写锁下经 `base_state` 逐字节核验：一致则还原（改写→写回原文、新建→删除、删除→重建），已恢复则幂等跳过，任一文件落盘后被修改则 fail-closed 拒绝且一处不改。
   - [`crates/ziyuan-cli/src/args.rs`](../../crates/ziyuan-cli/src/args.rs)、[`commands.rs`](../../crates/ziyuan-cli/src/commands.rs)、[`main.rs`](../../crates/ziyuan-cli/src/main.rs)、[`help.rs`](../../crates/ziyuan-cli/src/help.rs)：新增 `ziyuan revert <诏令ID> [--dry-run] [--json]` 并接入 shell 补全。
   - [`crates/ziyuan-web/src/lib.rs`](../../crates/ziyuan-web/src/lib.rs)、[`edicts.rs`](../../crates/ziyuan-web/src/edicts.rs)、[`index.html`](../../crates/ziyuan-web/src/index.html)：新增 `GET /api/tasks/{id}/changes/revert`（观政只读可预览）与 `POST /api/tasks/{id}/changes/revert`（仅皇帝、观政 403、版本不符 409），已落盘奏本新增「安全回滚」按钮（先预览确认再执行）。
3. **文档与版本登记**
   - 同步更新 [`docs/guide.md`](../guide.md)、[`docs/architecture.md`](../architecture.md)、[`docs/roadmap.md`](../roadmap.md)、[`docs/README.md`](../README.md)、[`docs/releasing.md`](../releasing.md) 与 [`CHANGELOG.md`](../../CHANGELOG.md)。
   - 登记次版本 `1.33.0`（[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs) `RELEASES` 序号 69，零新增事件与玉玺代码，不提高旧事件簿读取门槛）。
