# 1.17.0 验收记录

更新：2026-11-20。本页记录发版提交写入前在本机已执行的检查。标签 `v1.17.0`、四平台发行包及 crates.io 自动发布要等标签推送后由 CI 完成，这里不提前写成已完成。

## 本版范围

- 都察院逐段审 diff 与验功修复：
  - 修复 1.16.0 引入 `replace_text` 后验功依据未随之失效的遗漏：`write_file` 与 `replace_text` 的成功暂存写入均会使旧测试记录失效，御史系统提示同步补全 `replace_text`。
  - 都察院复核呈报改动时附带改动概览，将呈报 diff 包入 `guard::fence` 隔离边界，提升 diff 截断与回复字数上限，并要求逐段输出 `第 n 段：驳回建议／关注／无异议——理由`。
  - 新增 `parse_hunk_reviews` 解析与三端展示：`ziyuan diff` 在段头下附注御史意见（`--plain` 保持纯 diff），Web `/api/state` 挂接各段意见并在段头下展示及提供「取消勾选御史建议驳回的段」辅助按钮，TUI 在段头下彩色展示御史批注。御史意见仅作参考，绝不自动驳回或落盘。
- 轻量版「条陈」（先只读方案、后收窄范围授写权）：
  - 翰林院新增内置只读模板「条陈」（`PLAN_TEMPLATE`），要求回奏单列「拟改路径：」并附改动方案与验证方式。
  - 新增 `ziyuan-app::plan` 规划与授写权逻辑：提取拟改路径、过滤越界与禁区（`.env*`、`.git`、`.jj`、`.ziyuan`）、将拟新建文件收拢至最近已有父目录并折叠冗余子路径、提取不到时回退原范围。
  - 接入 CLI（`ziyuan edict --plan` / `--from-plan <id>` 及三壳补全）、Web（`POST /tasks/{id}/from-plan`、`plan_draft` 与观政只读隐藏的折叠面板）与 TUI（已完成的只读诏令按 `P` 预填弹窗）。
- 文档同步：更新 `README.md` 与[使用指南](../guide.md)。
- 工作区 crate、依赖、`Cargo.lock` 与 `ziyuan-storage::RELEASES` 登记 `1.17.0`。不新增朝廷事件类型，不提高旧事件簿读取门槛。
