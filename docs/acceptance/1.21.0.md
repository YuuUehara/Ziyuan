## 已知边界（未在本版承诺）

- 运行中调整不支持改写已开始（`Assigned`）或已结束（`Completed`/`Failed`/`Cancelled`）子诏令的依赖，也不支持跨父任务引用或打破单层 2–8 子诏令上限。
- TUI 展示动态更新后的依赖与受阻状态，运行中追加/改依赖操作暂由 CLI 与 Web 提供。
- 四平台发布打包与 crates.io 可信发布由 GitHub Actions `release.yml` 在打标推送后自动执行。
