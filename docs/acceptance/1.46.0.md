# 1.46.0 验收记录

对应提交：本发布提交（`1.46.0`）。

## 核对项

1. **译文记忆增量向量复用（`ziyuan-app::memory`）**
   - [`crates/ziyuan-app/src/memory.rs`](../../crates/ziyuan-app/src/memory.rs) 在每次 `memory_build` 完整复核定稿资格与水位的前提下，对模型签名（`provider / model / revision / dim / metric`）、段落 `identity`、原文及 `input_sha256` 均匹配的记录直接复用已有向量，仅向提供方提交新增或改动原文；空库或全量命中缓存时仍执行一次空输入校验以拦截未配置或未授权提供方（已授权远程提供方不触网），签名变更或坏缓存自动全量重算修复。
   - [`crates/ziyuan-app/tests/memory.rs`](../../crates/ziyuan-app/tests/memory.rs) 新增 `incremental_build_reuses_unchanged_vectors_and_rebuilds_on_signature_or_corrupt_cache` 验证首次建库、无变更零外发复用、新增章节增量嵌入且产物与全量建库逐字节一致、模型签名切换重算与坏缓存修复；[`crates/ziyuan-cli/src/memory_commands.rs`](../../crates/ziyuan-cli/src/memory_commands.rs) 与 [`crates/ziyuan-web/src/text/memory_refs.rs`](../../crates/ziyuan-web/src/text/memory_refs.rs) 同步输出 `reused` 与 `embedded`。
2. **翰林院单项目四阶段度支账本（Web + `neo-panel`）**
   - [`crates/ziyuan-web/src/text/qa_verify.rs`](../../crates/ziyuan-web/src/text/qa_verify.rs) 与 [`crates/ziyuan-web/src/lib.rs`](../../crates/ziyuan-web/src/lib.rs) 新增只读接口 `GET /api/text/{project}/usage`（观政可读，未建朝返回 `founded: false` 与四阶段空小计）。
   - [`crates/ziyuan-web/src/project-usage.mjs`](../../crates/ziyuan-web/src/project-usage.mjs)、[`crates/ziyuan-web/src/neo-panel.mjs`](../../crates/ziyuan-web/src/neo-panel.mjs) 与 [`crates/ziyuan-web/src/index.html`](../../crates/ziyuan-web/src/index.html) 在「翰林院 → 通读交稿」与「垂拱枢机 → 译林枢机」提供宋韵五境全主题自适应的四阶段度支账本（纯 `createElement`/`textContent`，缺失用量标为未知、绝不填零，多币种分列）。
3. **候选术语交互审定台与一键收入草稿**
   - [`crates/ziyuan-web/src/materials/mod.rs`](../../crates/ziyuan-web/src/materials/mod.rs) 为 `/api/text/{project}/blocks/{block}/term-proposals` 增补观政可用的只读 `GET` 预览；[`crates/ziyuan-app/src/translation/materials/termbase.rs`](../../crates/ziyuan-app/src/translation/materials/termbase.rs) 补入 `«…»` 双角引号短语提取。
   - [`crates/ziyuan-web/src/materials-collab.mjs`](../../crates/ziyuan-web/src/materials-collab.mjs) 提供交互式候选术语审定台，支持段落一键定位、分类预选、单条或批量经 `POST /api/text/{project}/materials/quick-add` 并入本地暂定草稿（不自动批准生产上下文）。
4. **前后端巨型模块拆分、根仓库约定与版本登记**
   - 拆分 [`crates/ziyuan-web/src/text.rs`](../../crates/ziyuan-web/src/text.rs) 与 [`crates/ziyuan-cli/src/text_commands.rs`](../../crates/ziyuan-cli/src/text_commands.rs) 为职责清晰的子模块，从 `index.html` 抽出 `text-versions.mjs`、`verification-panel.mjs` 与 `materials-collab.mjs`；新增根 [`AGENTS.md`](../../AGENTS.md) 并规范化 `scripts/*.bat` CRLF 行尾。
   - 同步更新 [`Cargo.toml`](../../Cargo.toml)、[`Cargo.lock`](../../Cargo.lock)、[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs)（`RELEASES` 序号 83 `1.46.0`）、[`CHANGELOG.md`](../../CHANGELOG.md)、[`docs/README.md`](../README.md)、[`docs/releasing.md`](../releasing.md)、[`docs/roadmap.md`](../roadmap.md) 与 [`docs/stability.md`](../stability.md)。
