# 1.16.1 验收记录

更新：2026-11-20。本页记录发版提交写入前在本机已执行的检查。标签 `v1.16.1`、四平台发行包及 crates.io 自动发布要等标签推送后由 CI 完成，这里不提前写成已完成。

## 本版范围

- Web 界面画风与排版修复：
  - 为「向导式新建」弹窗（`#material-wizard`）与背景遮罩补齐三主题纸墨样式，给弹窗内与翻译记忆动态创建的文本输入框补齐 `type="text"`，并将基础输入框样式扩展至 `input:not([type])`。
  - 统一「翰林院 → 资料」中本地资料编辑器（`.materials-editor`）的页签激活态、条目选中态、按钮间距、分组框与可选项复选框样式。
  - 补齐「文华殿」底部「官职配置」与「户部度支」连续 `.row` 的垂直间距；移除「武英殿」空实录列表项前的 `1.` 编号；对齐「作品关注」定时与自动入队勾选项与输入框底线。
  - 修复 390px 窄屏下殿阁导航角标遮挡「华盖殿」文字，以及配色切换组折行后的左侧多余缩进。
- TUI 下诏弹窗交互改进：在 `InputKind::Edict` 中标出当前焦点栏位（`▶`／`>`）并区分未激活栏位样式，增加 `↑↓ 换项 · Enter 下诏 · Esc 取消` 提示，同时对小终端的光标纵坐标做边界限制。
- 文档与截图同步：刷新 `web-officials.png`、`web-dag.png`、`web-dag-schedule.png`、`web-follow.png`、`web-text-memory.png`、`web-text-memory-narrow.png` 六张活跃指南截图，并修正[使用指南](../guide.md)中的三处图注。
- 工作区 crate、依赖、`Cargo.lock` 与 `ziyuan-storage::RELEASES` 登记 `1.16.1`。不新增朝廷事件类型，不提高旧事件簿读取门槛。
