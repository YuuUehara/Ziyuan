## 实现与边界

- 追加不可变词证：段号、原文真实短引、来源文字、定位、核对说明、适用语境及暂定／确认。只存本地，不抓取链接、不自动外发或提升到批准上下文。
- 六类显式复核：主语／说话者、施受／否定、数量／倍数、时序、称谓／关系、笑点／增释。意见处置与问题解决状态独立；可关联本块已完成模型审校的真实短引与本段词证。
- 项目内 `verification.json` 使用既有有锁版本化存储：schema 1、16 MiB、合计 10000 条上限。指纹绑定材料快照及记录序号，锁内重查；旧指纹不能覆盖并发意见，不承诺与任意外部编辑器原子隔离。
- 历史保留源文、译文、朱批、来源／审校任务及前次记录，材料变化后旧记录失效；前后译文来自相邻不可变记录，不拿模型“已修正”的说法冒充实际差异。
- 结构有效、关联意见已处理、操作者复核、有效定稿分别报告；不是专家终审，不新增定稿门槛、不自动准奏或启动下一块。批准词表只给字面提示，自由文本 `scope` 仍须人工判断适用性。
- CLI 与 Web 共用应用层；未建朝廷的项目可离线记录。viewer 可读不能写，Web 错误不泄漏本地路径。缺失 JSON 状态的只读查询不再创建空锁文件；已有状态仍持共享锁读取。

用法及完整 JSON 见[文本工具](../text-projects.md#unreleased--14-第三批-b词证与逐段勘校)，兼容与权限见[稳定性约定](../stability.md#unreleased--14-第三批-b词证与逐段勘校)。

## 浏览器实跑

使用独立自写五段日文夹具与故意错误译文、合法回放的任务／审校夹具；未调用模型、未修改真实小说试验。Chromium、2× DPR，1280×900 与 390×844 CSS 像素，天青／墨分／青绿均检查，无横向溢出；窄屏不是实机或触控测试。

- 实际保存确认词证，来源含长 URL 文字；核验追加记录及原文短引。填写理由后等待轮询、切换段落再返回，输入保留；浏览器重载后保留已存历史，未保存表单按说明重置，不从模型建议自动填入。
- 实际保存“接受／未解决”及任务 #2 精确短引、词证 #1。随后回读并显式保存“接受／已解决”：本项状态与下拉选择一致，待核对数从 6 降到 5，其他五项仍为待查／未检查，操作者复核仍为假。
- 修改夹具译稿后，原记录显示旧材料、旧译文不变，旧表单保存禁用且理由保留。重新核对保存后显示“狐狸／数学主任”到“狸／副校长”的真实前后差异及朱批。不能由这段手写修订推导模型纠错收益。
- viewer 页面无可见保存按钮，直接 POST 返回 403，历史仍可展开。浏览器注入一次读取失败，单条错误可见、已有历史保留，恢复读取后清除；逆序返回旧响应被忽略。后两项是受控客户端故障，不冒称真实网络中断测试。
- 浏览器检查发现只发 `change` 的下拉操作未更新草稿；已同时监听 `input`／`change`，重跑后核验持久化枚举、关联依据与待核对数。增加明确保存反馈；记录序号变化也会使确认过期，提示不再一律误称原稿改变。

本线程 `.amp/in/artifacts/1.4-third-batch-3b/` 保存并检查了三主题桌面／窄屏、viewer、历史对照、读取失败截图及 `review-flow.mp4`／`.loop.webp`。真实指针经过相邻处置／解决状态控件，键盘修改状态和理由后主动刷新确认并保存；录屏以 5 fps 接触表检查，持久化结果另由实际响应验证，不仅凭截图或录屏宣称成功。临时夹具、服务和辅助脚本已清理，不是 CI 的隐含依赖。
