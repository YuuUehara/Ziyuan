# 1.14.0 验收记录

日期：2026-11-12。本页区分本地功能回归、候选提交 CI、正式下载包与 crates.io 的结果；候选检查通过不代表已经正式发行。

## 本版范围

- 完整译书工作区备份与新目录恢复，TXT 追加与单章原文修订。
- 跨章待查及依据变化后的复核，连续双语通读与交稿预检。
- 保留文学标记的 HTML 成稿，全文检索及人工草稿字面替换。
- 纯文本 TMX 交换、翻译记忆与评论保存加固、网页管理入口。
- Web DOCX／EPUB／SRT 导入导出，字幕时间轴、审批与格式损失检查。
- 第二版术语、人物、称谓提示逐段筛选；三主题窄屏布局修复。

## 边界与未测项目

- 复杂 DOCX／EPUB 分页、脚注、浮动对象、真实大型作品及出版级排版未完成实物往返验收；不能将合成样本测试当作文学质量或复杂格式保证。
- TMX 仅支持纯文本，原文更新仅支持受约束的 UTF-8 TXT；拆合段、章节重排及复杂行内交换不在支持范围。
- 本地浏览器验证不覆盖所有浏览器、输入法与辅助技术；TUI 人工译稿入口仍未开放。
- 备份包含共用审批历史，可能有代码任务正文；不包含模型凭据配置，不等于单本书分享包。
