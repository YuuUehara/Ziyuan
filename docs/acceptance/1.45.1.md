# 1.45.1 验收记录

对应提交：本发布提交（`1.45.1`）。

## 核对项

1. **六殿与单栏卡片居中阅读布局**
   - [`crates/ziyuan-web/src/index.html`](../../crates/ziyuan-web/src/index.html) 将 `.hall`（`1400px`）、`.card.narrow`（华盖殿 `960px`）与 `.card.history`（起居注 `1120px`）改为 `width: 100%; margin-inline: auto;`，消除宽屏及单栏模块贴左留出大片右侧空白的问题。
2. **人工双语译稿框严格对齐**
   - [`crates/ziyuan-web/src/human-editor.mjs`](../../crates/ziyuan-web/src/human-editor.mjs) 与 [`crates/ziyuan-web/src/index.html`](../../crates/ziyuan-web/src/index.html) 将 `.human-mark-tools` 和 `.human-tm-suggest` 迁入 Grid 第二行 `.human-target-extras`，移除 `34px` 魔数底距，确保原文与译文两框在译文记忆展开、工具栏折行、只读及窄屏单列下均严格顶底对齐；[`crates/ziyuan-web/src/human-editor.test.mjs`](../../crates/ziyuan-web/src/human-editor.test.mjs) 补齐回归断言。
3. **多语种全链路同步与「X语」用语规范**
   - [`crates/ziyuan-app/src/text_project/model.rs`](../../crates/ziyuan-app/src/text_project/model.rs)、[`crates/ziyuan-app/src/text_project/store.rs`](../../crates/ziyuan-app/src/text_project/store.rs)、[`crates/ziyuan-web/src/text.rs`](../../crates/ziyuan-web/src/text.rs) 与 [`crates/ziyuan-cli/src/text_commands.rs`](../../crates/ziyuan-cli/src/text_commands.rs) 同步放行 `ru / es / it`；[`crates/ziyuan-app/src/text_project/encoding.rs`](../../crates/ziyuan-app/src/text_project/encoding.rs)、[`crates/ziyuan-web/src/import-decoder.mjs`](../../crates/ziyuan-web/src/import-decoder.mjs) 与 [`crates/ziyuan-web/src/continuity.mjs`](../../crates/ziyuan-web/src/continuity.mjs) 补齐 `es / it` Windows-1252 旧编码解码；[`crates/ziyuan-app/src/translation/verification.rs`](../../crates/ziyuan-app/src/translation/verification.rs) 补齐俄／西／意语源语残留检测与单测；前端导入支持解码语言覆盖与即时重解码，语种文案统一为「X语」。
4. **青空文库导入边界修复与 v1 清单兼容**
   - [`crates/ziyuan-app/src/text_project/document.rs`](../../crates/ziyuan-app/src/text_project/document.rs) 隐式基底补入 `ヶ / ヵ / 〆 / 〇`，按括号深度安全跳过嵌套 `［＃…］` 批注，阻止普通竖线 `｜` / `|` 跨句或带前导空白误吞后方注音，同时严格维持 `v1_warning_ranges_remain_readable_for_existing_projects` 兼容契约。
5. **版本登记与文档同步**
   - 同步更新 [`Cargo.toml`](../../Cargo.toml)、[`Cargo.lock`](../../Cargo.lock)、[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs)（`RELEASES` 序号 82 `1.45.1`）、[`CHANGELOG.md`](../../CHANGELOG.md)、[`docs/README.md`](../README.md)、[`docs/releasing.md`](../releasing.md) 与 [`docs/roadmap.md`](../roadmap.md)。
