# 1.37.0 验收记录

对应提交：本发布提交（`1.37.0`，含前置特性提交 `8edb3ef9`）。

## 核对项

1. **基于前件实录的只读「续问／追查」闭环（CLI + Web + TUI，零新事件类型）**
   - [`crates/ziyuan-app/src/follow_up.rs`](../../crates/ziyuan-app/src/follow_up.rs) 与 [`lib.rs`](../../crates/ziyuan-app/src/lib.rs)：新增 `Session::issue_follow_up`、`FollowUpDraft`、`can_follow_up_task`、`draft_follow_up`、`follow_up_edict_text`；代码级剥离 `WriteFile`、`RunTests` 与外部 MCP 工具并确保授予 `ReadFile`＋`SearchCode`，以 `<前件实录 ...>` 围栏隔离前件诏令、回奏摘要、变更文件列表与都察院意见。
   - [`crates/ziyuan-cli/src/args.rs`](../../crates/ziyuan-cli/src/args.rs)、[`commands.rs`](../../crates/ziyuan-cli/src/commands.rs) 与 [`help.rs`](../../crates/ziyuan-cli/src/help.rs)：新增 `ziyuan edict --follow-up <ID> [--dept <部门>] [--scope <路径>]... [--queue] <追问内容>` 及 bash／zsh／fish 补全。
   - [`crates/ziyuan-web/src/edicts.rs`](../../crates/ziyuan-web/src/edicts.rs)、[`json.rs`](../../crates/ziyuan-web/src/json.rs)、[`lib.rs`](../../crates/ziyuan-web/src/lib.rs) 与 [`index.html`](../../crates/ziyuan-web/src/index.html)：`/api/state` 附带 `follow_up_draft`，新增 `POST /api/tasks/{id}/follow-up`（观政只读回 403）与可折叠续问卡片。
   - [`crates/ziyuan-tui/src/app.rs`](../../crates/ziyuan-tui/src/app.rs)、[`input.rs`](../../crates/ziyuan-tui/src/input.rs) 与 [`render.rs`](../../crates/ziyuan-tui/src/render.rs)：诏令页新增 `Q` 快捷键弹出两栏只读续问弹窗（`Tab` 换部、`↑↓` 切栏）。
2. **大型仓库增量符号索引缓存（`.ziyuan/index/symbols-v1.json`）**
   - [`crates/ziyuan-runtime/src/tools/index.rs`](../../crates/ziyuan-runtime/src/tools/index.rs)、[`symbols.rs`](../../crates/ziyuan-runtime/src/tools/symbols.rs) 与 [`tools.rs`](../../crates/ziyuan-runtime/src/tools.rs)：基于标准库与 `serde_json` 实现按路径与 `(mtime_secs, mtime_nanos, size)` 校验的增量符号索引缓存（上限 20,000 文件、临时文件原子重命名、仅在 `.ziyuan/` 存在时持久化），附带 256-bit 3-hash FNV-1a 标识符布隆过滤器加速 `find_references` 免读盘跳过；暂存改动实时覆盖且不污染持久化索引。
3. **户部度支 CSV／JSON 导出与 Web／TUI 交互补齐**
   - [`crates/ziyuan-app/src/reports.rs`](../../crates/ziyuan-app/src/reports.rs)：新增 `DuzhiRow`、`DuzhiBudget`、`DuzhiExport`、`duzhi_export`、`duzhi_export_csv`（RFC 4180＋可选 UTF-8 BOM）与 `duzhi_export_json`；打通 CLI `ziyuan budget --export <文件> [--format csv|json] [--bom]` 与 Web `GET /api/duzhi/export?format=csv|json&bom=1`（观政只读可下载）及页面导出按钮。
   - [`crates/ziyuan-web/src/index.html`](../../crates/ziyuan-web/src/index.html)：新增可折叠工具调用历史轨迹（`tool-trace-history`，每件任务上限 200 条）与 `Ctrl+K`／`Cmd+K` 全局命令面板（严格 `createElement`／`textContent` 无 HTML 拼串）。
   - [`crates/ziyuan-tui/src/human.rs`](../../crates/ziyuan-tui/src/human.rs)、[`input.rs`](../../crates/ziyuan-tui/src/input.rs) 与 [`render.rs`](../../crates/ziyuan-tui/src/render.rs)：新增 `B` 快捷键弹出 `translation_overview_report()` 全库译书项目概览弹窗并更新底栏提示。
4. **文档与版本登记**
   - 同步更新 [`Cargo.toml`](../../Cargo.toml)、[`Cargo.lock`](../../Cargo.lock)、[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs)（`RELEASES` 序号 73 `1.37.0`）、[`docs/guide.md`](../guide.md)、[`docs/roadmap.md`](../roadmap.md)、[`docs/README.md`](../README.md)、[`docs/releasing.md`](../releasing.md) 与 [`CHANGELOG.md`](../../CHANGELOG.md)。
