# 1.28.0 验收记录

对应提交：本发布提交（`1.28.0`）。

## 核对项

1. **同一模型回合内只读工具并发执行**
   - [`crates/ziyuan-runtime/src/agent_loop.rs`](../../crates/ziyuan-runtime/src/agent_loop.rs) 的 `Tool` trait 新增默认返回 `false` 的 `is_read_only(&self) -> bool`（写操作、测试与外部 MCP 工具维持串行）。
   - [`crates/ziyuan-runtime/src/tools.rs`](../../crates/ziyuan-runtime/src/tools.rs) 与 [`crates/ziyuan-runtime/src/tools/vcs.rs`](../../crates/ziyuan-runtime/src/tools/vcs.rs) 将 10 项无副作用只读工具（`read_file`、`list_files`、`search_code`、`file_outline`、`find_symbols`、`find_references`、`search_records`、`vcs_status`、`vcs_diff`、`vcs_log`）标记为只读。
   - `run_with_context` 在同一回合内遇到连续 2 条及以上只读工具调用时，通过 `std::thread::scope` 并发执行（每批上限 8 线程），仍严格按原始调用顺序触发 `hooks.tool_invoked`、`guard::scan` / `hooks.suspicion` 并写回 `Message::ToolOutput`；遇到写工具、测试或外部 MCP 工具则保持严格串行。
   - 单元测试 `parallel_readonly_tools_run_concurrently_and_preserve_order`（使用 3 方 `Barrier` 证明真并发）与 `mixed_write_and_read_tools_keep_writes_sequential` 通过。

2. **仓库约定文件（`AGENTS.md` / `CLAUDE.md`）受控注入**
   - [`crates/ziyuan-runtime/src/lib.rs`](../../crates/ziyuan-runtime/src/lib.rs) 新增 `load_repo_conventions`，在玉玺授予 `ReadFile` 且范围覆盖仓库根目录时，按 `AGENTS.md` 优先于 `CLAUDE.md` 的顺序读取首份非空 UTF-8 常规文件（不跟随符号链接、单次读取上限 64 KiB、注入摘要上限 4 KiB 并按 UTF-8 字符边界安全截断）。
   - 注入前经 `guard::scan` 检测劫持指令并通过 `hooks.suspicion("convention:<file>", ...)` 上报锦衣卫，正文以本轮随机 `nonce` 套上外来文书围栏（`guard::fence`），明确声明仅供参考、不得覆盖系统指令或玉玺权限。
   - 单元测试 `conventions_prioritize_agents_md_respect_seal_and_truncate_utf8` 与 `agent_backend_fences_conventions_and_reports_hijack_suspicion` 通过。

3. **TUI 与 CLI/Web 能力对齐**
   - [`crates/ziyuan-tui/src/actions.rs`](../../crates/ziyuan-tui/src/actions.rs)、[`crates/ziyuan-tui/src/input.rs`](../../crates/ziyuan-tui/src/input.rs)、[`crates/ziyuan-tui/src/app.rs`](../../crates/ziyuan-tui/src/app.rs) 与 [`crates/ziyuan-tui/src/render.rs`](../../crates/ziyuan-tui/src/render.rs)：
     - 诏令页新增 `F`（尚书并行写分办，调用 `plan_split_with_options(..., true, Some(&root))`，非 `jj` 仓库 fail-closed）；
     - 新增 `A`（运行中向已分办原诏令追加子诏令，三项弹窗支持内容、承办官 ID 与前置依赖 ID）与 `E`（运行中修改待办子诏令的前置依赖）；
     - 增强 `V`（打回再改一轮），在状态栏同时汇总上轮被驳回段号与都察院逐段批注（`驳回建议` / `关注`）段号。
   - TUI 单元测试 `tui_parallel_split_fails_closed_and_dag_add_and_deps_work` 与 `tui_shows_hunk_censure_and_issues_write_edict_from_plan` 通过。

## 边界

- 并发只读执行仅限同一模型回合内连续的纯只读工具；任何写文件、测试或外部 MCP 工具仍严格串行。
- 仓库约定注入仅读仓库根目录常规文件 `AGENTS.md` / `CLAUDE.md`，不跟随符号链接，不绕过玉玺 `ReadFile` 与 `scope` 约束。
