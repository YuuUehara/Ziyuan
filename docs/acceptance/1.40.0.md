# 1.40.0 验收记录

对应提交：本发布提交（`1.40.0`，含前置功能提交 `b861ed54`）。

## 核对项

1. **原生 Anthropic Messages API 与 Google Gemini API 适配（实验性，零新增事件与玉玺代码）**
   - [`crates/ziyuan-llm/src/anthropic.rs`](../../crates/ziyuan-llm/src/anthropic.rs)：直连 `/v1/messages`，发送 `x-api-key` 与 `anthropic-version: 2023-06-01`，完整解析 SSE `text_delta`、`thinking_delta`、`input_json_delta`、`tool_use`／`tool_result` 与最多 3 处 `cache_control: {"type":"ephemeral"}` 断点，精确记录 `cache_read_input_tokens` 与 `cache_creation_input_tokens`，并在 `429`/`529`/`5xx` 下按退避重试。
   - [`crates/ziyuan-llm/src/gemini.rs`](../../crates/ziyuan-llm/src/gemini.rs)：直连 `models/{model}:streamGenerateContent?alt=sse`，通过 `x-goog-api-key` 请求头鉴权（绝不拼入 URL），支持 `systemInstruction`、`functionDeclarations`（自动剔除 `$schema`／`additionalProperties`）、`functionCall`／`functionResponse`、`thought` 推理捕获与 `cachedContentTokenCount`。
   - 两项原生接口在 [`docs/stability.md`](../stability.md#实验性) 明确登记为实验性（仅经本地模拟 HTTP 服务测试，尚未以真实付费账号实测）。
2. **异构多模型路由表（`.ziyuan/models.json`）、按部派模与多币种度支**
   - [`crates/ziyuan-llm/src/config.rs`](../../crates/ziyuan-llm/src/config.rs) 与 [`crates/ziyuan-llm/src/lib.rs`](../../crates/ziyuan-llm/src/lib.rs)：强制禁止明文 `api_key`/`token`/`secret` 字段（仅存 `api_key_env` 环境变量名，256 KiB／64 项上限、拒绝符号链接），`Catalog` 按配置名异构路由至 OpenAI／Anthropic／Gemini／ChatGPT，缺凭据仅延迟在对应官职调用时报错；新增主流 Claude／GPT／Gemini 美元参考价与单项自定义单价。
   - [`crates/ziyuan-app/src/personnel.rs`](../../crates/ziyuan-app/src/personnel.rs) 新增 `Session::set_department_model`（单次提交原子设置整部三职）；[`crates/ziyuan-app/src/reports.rs`](../../crates/ziyuan-app/src/reports.rs) 修复多币种成本汇总，按币种分别累计（绝不跨币种相加）。
   - [`crates/ziyuan-cli`](../../crates/ziyuan-cli/src/commands.rs) 新增 `ziyuan model list [--json]` 与 `ziyuan model --dept <部门> <模型|配置名|default>`；[`crates/ziyuan-web`](../../crates/ziyuan-web/src/personnel.rs) 扩展 `POST /api/offices/model` 支持 `{ department, model }`（观政只读 403），`/api/state` 暴露非机密 `model_profiles` 摘要并在 [`index.html`](../../crates/ziyuan-web/src/index.html) 提供配置补全与「同部」一键设置。
3. **版本登记与文档同步**
   - 同步更新 [`Cargo.toml`](../../Cargo.toml)、[`Cargo.lock`](../../Cargo.lock)、[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs)（`RELEASES` 序号 76 `1.40.0`）、[`docs/guide.md`](../guide.md)、[`docs/stability.md`](../stability.md)、[`docs/roadmap.md`](../roadmap.md)、[`docs/README.md`](../README.md)、[`docs/releasing.md`](../releasing.md) 与 [`CHANGELOG.md`](../../CHANGELOG.md)。
