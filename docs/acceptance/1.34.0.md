# 1.34.0 验收记录

对应提交：本发布提交（`1.34.0`，含前置特性提交 `a3e57502`、`f3b73026`、`cb966083`）。

## 核对项

1. **Windows 原生号舍 W3 断网长连接 stdio MCP 沙箱**
   - [`crates/ziyuan-sandbox-windows/src/lib.rs`](../../crates/ziyuan-sandbox-windows/src/lib.rs) 与 [`windows.rs`](../../crates/ziyuan-sandbox-windows/src/windows.rs)：新增 `StdioLaunchSpec`、`SandboxedStdioChild` 与 `spawn_stdio_sandboxed`，通过匿名双向管道＋`PROC_THREAD_ATTRIBUTE_HANDLE_LIST`、0 能力 AppContainer、按任务独立隐藏桌面 `PrivateDesktop` 与 `KILL_ON_JOB_CLOSE` Job Object 运行长连接子进程并整树排空清理。
   - [`crates/ziyuan-runtime/src/haoshe.rs`](../../crates/ziyuan-runtime/src/haoshe.rs) 与 [`mcp.rs`](../../crates/ziyuan-runtime/src/mcp.rs)：新增 `haoshe::spawn_stdio` 并接入 Windows 断网只读快照 stdio MCP 沙箱，统一规范化 8.3 短路径；Windows 测试脚本改为纯 .NET `JavaScriptSerializer` 消除 Windows Server 2025 AppContainer 下 PowerShell cmdlet 模块自动加载问题；开放联网、域名白名单与 `haoshe.write` 维持失败关闭。
2. **Prompt Caching 与缓存用量透明**
   - [`crates/ziyuan-core/src/usage.rs`](../../crates/ziyuan-core/src/usage.rs)：`TokenUsage` 扩展 `cache_read`、`cache_write` 与 `cache_hit_rate()`，零缓存保持原 JSON 与 `Display` 兼容。
   - [`crates/ziyuan-storage/src/codec.rs`](../../crates/ziyuan-storage/src/codec.rs)、[`lib.rs`](../../crates/ziyuan-storage/src/lib.rs) 与 [`compat.tsv`](../../crates/ziyuan-storage/src/compat.tsv)：`USAGE` 零缓存保持 5/6 列旧编码，非零缓存追加 `cache_read`、`cache_write` 两列，登记 `RELEASES` 序号 70（`1.34.0`）并补齐跨版兼容样本。
   - [`crates/ziyuan-llm/src/lib.rs`](../../crates/ziyuan-llm/src/lib.rs)、[`responses.rs`](../../crates/ziyuan-llm/src/responses.rs) 与 [`chatgpt.rs`](../../crates/ziyuan-llm/src/chatgpt.rs)：新增 `PromptCache`（`ZIYUAN_LLM_PROMPT_CACHE=auto|anthropic|on|off`）自动为 Claude/Anthropic 注入最多 3 处 `cache_control: {"type":"ephemeral"}` 断点，兼容解析 OpenAI、Responses API、DeepSeek 与 Anthropic 缓存用量字段。
   - [`crates/ziyuan-app/src/reports.rs`](../../crates/ziyuan-app/src/reports.rs)、[`crates/ziyuan-web/src/json.rs`](../../crates/ziyuan-web/src/json.rs)、[`index.html`](../../crates/ziyuan-web/src/index.html) 与 [`crates/ziyuan-tui/src/render.rs`](../../crates/ziyuan-tui/src/render.rs)：度支奏销、Web 界面与 TUI 页头透明展示缓存命中与写入统计。
3. **TUI 安全回滚预览弹窗与确认热键**
   - [`crates/ziyuan-tui/src/app.rs`](../../crates/ziyuan-tui/src/app.rs)、[`input.rs`](../../crates/ziyuan-tui/src/input.rs)、[`render.rs`](../../crates/ziyuan-tui/src/render.rs) 与 [`tests.rs`](../../crates/ziyuan-tui/src/tests.rs)：新增 `Modal::Revert(RevertReport)` 与诏令页 `Z` 快捷键，逐文件预览操作与磁盘核验状态；仅在安全且存在可回滚文件时响应 `y` 执行乐观版本回滚，冲突或已全部恢复时 fail-closed 阻断且不动盘。
4. **文档与版本登记**
   - 同步更新 [`docs/guide.md`](../guide.md)、[`docs/architecture.md`](../architecture.md)、[`docs/stability.md`](../stability.md)、[`docs/roadmap.md`](../roadmap.md)、[`docs/README.md`](../README.md)、[`docs/releasing.md`](../releasing.md) 与 [`CHANGELOG.md`](../../CHANGELOG.md)。
