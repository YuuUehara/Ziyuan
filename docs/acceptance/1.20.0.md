## 已知边界（未在本版承诺）

- 非 `jj` 版本库（纯 `git` 或普通目录）不支持工作副本隔离：`--parallel-writes` / `parallel_writes: true` 会失败关闭，默认串行分办与内存暂存准奏仍照常工作。
