# 1.30.0 验收记录

对应提交：本发布提交（`1.30.0`）。

## 核对项

1. **Windows 原生号舍 W2 工程加固、模块拆分与真实工具链实测（`ziyuan-sandbox-windows`）**
   - **生产 FFI 核心与探针解耦**：将 W1a–W1d/W2 验证探针 CLI 迁入独立私有模块 [`crates/ziyuan-sandbox-windows/src/probe.rs`](../../crates/ziyuan-sandbox-windows/src/probe.rs)，[`crates/ziyuan-sandbox-windows/src/windows.rs`](../../crates/ziyuan-sandbox-windows/src/windows.rs) 收窄至仅含生产必需的 AppContainer/LPAC、ACL/SID、Job Object 与句柄生命周期 Win32 FFI（零 WinSock、零探针 harness），大幅缩小后续独立 unsafe 审计面。
   - **按任务独立隐藏桌面（`PrivateDesktop` / Alternate Desktop）与零静态 `user32.dll` 依赖**：`AppContainerChildCapable` 通过动态加载 `%SystemRoot%\System32\user32.dll` 为每次执行创建仅授权本任务 AppContainer SID 最小无界面初始化权限（`0x000200C3`，显式排除 `DESKTOP_SWITCHDESKTOP` 与钩子）的独立隐藏桌面，Job 进程树排空后立即 `CloseDesktop` 销毁；严格 LPAC 模式与 crate 本身均不引入静态 `user32.dll` 导入。
   - **有界尾部输出读取与完整任务私有环境**：`LaunchSpec`／`ShellSpec` 新增 `max_output_bytes`（默认 16 MiB，`DEFAULT_MAX_OUTPUT_BYTES`），`RunResult` 新增 `output_truncated` 与 `total_output_bytes`，改为按文件尾偏移有界读取，避免失控命令大日志撑爆宿主内存；`build_environment` 显式提供指向本任务 profile 私有子目录的 `USERPROFILE`/`HOME`/`APPDATA`/`TEMP`/`TMP` 及由 `SystemRoot` 派生的 `WINDIR`/`ComSpec`/`SystemDrive`/`PATHEXT`，并禁止调用方覆盖全部 12 项保留变量。
   - **原生非管理员 Windows 11（`HOST_ELEVATED=0`）实测（`cargo test -p ziyuan-sandbox-windows --locked -- --nocapture`，12/12 通过）**：
     - `w2_bounded_output_reads_tail_without_unbounded_memory`：输出超 2 KiB 时以 `max_output_bytes: Some(256)` 仅读最后 256 字节（`output_truncated == true`、`total_output_bytes > 2048`、`FINAL_TAIL_MARKER` 完整）。
     - `w2_real_toolchain_runs_tests_in_sandbox_while_blocking_host_and_user_profile`：
       - 真实内置 **Windows PowerShell** 在 0 能力 AppContainer＋`PrivateDesktop` 内通过全部测试断言（副本读写成功、6 项私有环境变量均落在 `Packages\ziyuan.w1.*` 内不泄露宿主 `%USERPROFILE%`、读取宿主秘密文件报 `UnauthorizedAccessException`、连接宿主回环 TCP 被阻断且宿主机监听 `hits == 0`）；
       - 真实系统安装 **`Program Files` Git**（静态链接 `user32.dll`、带标准 `ALL APPLICATION PACKAGES:(RX)` 继承）在隔离副本内执行 `git --version` 与 `git --git-dir=. hash-object` 返回 `Exited(0)`；
       - 宿主用户目录下的 **`%USERPROFILE%\.cargo\bin\cargo.exe`** 未经准入直接执行返回 `拒绝访问`（非 0 退出），证实不会放宽宿主用户目录 ACL，亦明确 W2 工具链准入边界（需具备 `ALL APPLICATION PACKAGES:(RX)` 系统只读权限或任务私有只读副本）。

2. **运行时取消信号透传与 Windows MCP 边界明示（`ziyuan-runtime`）**
   - [`crates/ziyuan-runtime/src/haoshe.rs`](../../crates/ziyuan-runtime/src/haoshe.rs)：`ShellRunSpec` 新增 `cancel: Option<&'a AtomicBool>`，在 `run_shell` 等待循环中即时响应取消信号终止子进程并返回 `已取消（被主动终止）`，新增 `run_shell_off_honors_cancellation_flag` 单测覆盖。
   - [`crates/ziyuan-runtime/src/mcp.rs`](../../crates/ziyuan-runtime/src/mcp.rs)：Windows 下配置了 `haoshe` 的本地 stdio 外藩显式返回 `SandboxUnavailable`，明示 W2 首批仅覆盖一次性断网命令（`run_tests`），长连接双向管道 stdio 外藩留待 W3 处理。
