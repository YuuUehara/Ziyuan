# 1.4.1 验收记录

## 范围

本版仅调整 Web 注音字号、更新指南主图与说明，并承接 1.4 文档统一和代码任务计划；不是代码任务 4A／4B／4C 的功能交付。注音从正文的 72% 调为 60%，普通括号仍按字面保留。不改变解析、安全处理、事件格式、工具权限或审批规则，未新增付费模型调用。

## 已有验证

- 1.4.1 本地发布检查全部通过：`cargo fmt --all -- --check`、`cargo check --workspace --all-targets --all-features --locked`、`cargo test --workspace --locked`、`cargo clippy --workspace --all-targets --locked -- -D warnings`、`cargo build -p ziyuan-cli --locked` 与 `bash scripts/smoke.sh`（`ZiYuan smoke test PASS`）。
- 十一个 crate 的锁文件版本及内部精确依赖统一为 1.4.1；发布版本表只追加 1.4.1，不提高旧事件的最低读取版本。首次检查因构建缓存占满磁盘而中断，清理可重建缓存后重新执行；随后版本登记回归指出缺项，补齐后上述检查全部通过，没有忽略失败。
- 重建 CLI 后通过 `cargo test -p ziyuan-web --lib --locked`：39 passed、0 failed。
- Chromium、DPR 2 下检查了桌面、390 CSS 像素窄屏导入预览、确认导入后的原文区与长读音折行。14px 正文对应 8.4px 读音，窄屏页面宽度 390，预览及原文区域均无横向溢出。截图见[文本指南](../text-projects.md#预览与确认导入)，安全样例保持在[历史验收](1.4-first-batch.md#浏览器实跑)。
- 指南明确说明：「漢字」上方的小字 `かんじ` 是注音；`普通の説明（かんじ）はそのまま。` 内的括号是正文，不是 ruby。
