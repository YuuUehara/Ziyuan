# 1.15.0 验收记录

更新：2026-11-13。本页记录 1.15.0 源码候选的功能边界和本地检查。1.14.1 的发行结果见 [1.14.1 验收记录](1.14.1.md)。本页不表示已经打标签或公开下载包。

## 本版范围

- 原文追加和单章修订可以选 UTF-8 TXT、Markdown、DOCX、EPUB。TXT 和 Markdown 不超过 8 MiB；DOCX 和 EPUB 不超过 16 MiB，抽出来的正文超过 8 MiB 也会拒绝。压缩包里最多 4096 个文件，每个解开后不超过 32 MiB。先预览，再确认。修订时段落数和所属的块必须不变；拆段、合段或重排会整次拒绝。按 TXT 或 Markdown 导入的项目，不能再用 DOCX 或 EPUB 更新。命令行 `text import` 的纯 TXT 没有归档原件，修订时不会新建。已经有 DOCX 原件的，单章修订只接受 DOCX；已经有 EPUB 原件的，只接受 EPUB。覆盖前按内容摘要把旧原件放进原文历史。追加新章，或者项目不止一章时，已有原件保留，这次只改正文。已有译稿和批准不会被改掉。
- 终端「人工译稿」可以查看、改段、保存草稿、送审、准奏、核对和定稿。送审、准奏、定稿都要再按 `y`。保存不改正式译稿。改过的字会去掉这一段的注音、着重、粗体和斜体。
- 译文记忆默认不启用、不联网。`local` 仍是 `char-hash-v1`。`deterministic` 是另一套只在本机计算的固定算法。`remote` 要先 `text memory authorize`。建库时发送已授权项目里已定稿段落的原文，每次查询只发送这一次的查询文字。没授权、地址或模型不一致、项目不在名单里，都会拒绝，并且不联网。不读取 `ZIYUAN_LLM_*`。`text memory search` 和 `text tm suggest` 的结果只供参考，不写入本地记忆，不自动插入，也不自动批准。
- 不新增朝廷事件，不提高旧事件簿的最低读取版本。出现索引和段旁候选插入不纳入本版。

## 边界

- 追加 DOCX 或 EPUB 时，不更换已经保存的归档原件。没有归档原件时也不新建。回填仍用导入时留下的那份；纯文本导入没有这份原件。
- 终端不改注音、着重、粗体或斜体。改过文字的那一段，这些标记会被去掉。
- `local` 和 `deterministic` 都不理解意思。远程嵌入建库发送已定稿原文，查询只发送当次查询文字；没有做过译文质量评测。
- 未打标签，未推送 `v1.15.0`，未公开 GitHub Release，未向 crates.io 发布。
