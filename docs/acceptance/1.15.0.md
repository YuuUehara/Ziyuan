# 1.15.0 验收记录

更新：2026-11-13。本页记录 1.15.0 源码候选的功能边界和本地检查。1.14.1 的发行结果见 [1.14.1 验收记录](1.14.1.md)。本页不表示已经打标签或公开下载包。

## 本版范围

- 原文追加与单章修订接受 UTF-8 TXT、Markdown，以及 DOCX、EPUB。TXT／Markdown 正文最多 8 MiB；DOCX／EPUB 原件最多 16 MiB，抽出的正文仍不得超过 8 MiB。先预览再确认。修订须保持段落数量和块归属；拆段、合段、重排整次拒绝。按 TXT 或 Markdown 解析保存的项目不能改用 DOCX／EPUB。单章同格式修订可替换归档原件；追加不替换已有归档原件。已有译文和批准不会被静默改写。
- 终端「人工译稿」可查看块、修改段落文本、保存草稿、送审、准奏、核对落盘和定稿。送审、准奏、定稿都要再按 `y`。保存不写 `zh.json`。它调用与 CLI 相同的应用层。终端改字会清除该段标记；注音等标记仍在网页编辑。
- 译文记忆默认不启用、不联网。`local` 仍是 `char-hash-v1`。`deterministic` 是离线固定向量。`remote` 必须先 `text memory authorize`，只发送已授权项目的原文；未授权、端点或模型不一致、项目不在名单内时拒绝并且不发出请求。不读取 `ZIYUAN_LLM_*`。`text memory search` 与 `text tm suggest` 的结果只供参考，不写入 `tm.json`，不自动插入或批准。
- 不新增朝廷事件，不提高旧事件簿的最低读取版本。出现索引和段旁候选插入不纳入本版。

## 边界

- DOCX／EPUB 追加不改写已有归档原件，回填仍用导入时的原件。
- 终端不编辑注音、着重、粗体或斜体；这些仍用网页。
- 远程嵌入没有做语义质量评测。`deterministic` 与 `local` 都不理解文意。
- 未打标签，未推送 `v1.15.0`，未公开 GitHub Release，未向 crates.io 发布。
