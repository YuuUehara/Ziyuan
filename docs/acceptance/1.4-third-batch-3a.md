## 实现边界

- CLI／Web 从有效定稿搜索结果选择参考，显式预览额外外发材料，再确认一次初译或修订；默认不选。最多 8 条、8192 UTF-8 字节，不截断；完整持久化快照另限 32768 字节。
- 选择使用权威资料重查，不信任客户端正文、缓存内容或排名。CLI 跨项目显式授权且语言相同，Web 限当前项目；viewer 可预览，不能下诏。
- 新增 `TRANSREFS` 事件保存任务绑定和原译文快照；旧事件编码不变，最低读者为 1.4.0。会典缓存标记隔离新增字段，防止同包版本旧源码静默丢绑定。
- 同一提交身份、相同内容跨会话返回原任务；不同内容拒绝。下诏与绑定同次持久化。响应丢失时保留提交身份及原请求，不自动重发。
- 执行前在取得 worker permit 后重查；来源失效、手改或绑定不符时不进入模型后端。来源发送后再变化仍保留旧快照，未增加自动阻止定稿的来源依赖门控。
- 预览是完整的**额外参考材料**，不是常规原文、上下文、朱批及工具结果组成的整个模型对话。选中资料存入 `court.log`，外发和持久化隐私边界见[使用说明](../memory.md)。

## 真实请求边界

`crates/ziyuan-cli/tests/reference_execution.rs` 通过真实 `Session::run → Scheduler → AgentBackend → OpenAiCompatible`，只连接本地 HTTP／SSE 捕获服务；4 个测试并行与串行均通过，不是直接断言提示拼接函数。

- 三条候选只选中间 beta：初译、修订请求均出现一次完整预览材料；alpha／gamma 的原译文不出现。对照任务未选参考，工具能力保持相同。
- 来源译稿被改或退回后，持久化失败任务，模型 HTTP／模型事件／工具事件均为零。
- 单 worker 排队期间，先行任务回调改变来源：后续已分配的参考任务仍在取得许可后拒绝，无该任务模型请求。
- 响应丢失后用新会话重试仍返回原任务，不增加事件；失效历史快照仍能查看。

成功夹具只回复文本而不调用工具，会触发既有一次退回补做，因此成功任务有两次 HTTP 请求；不将任务数冒充请求数。普通翻译原有邻接材料及工具读取规则未被本批禁用，本测试的“未选不发”指所选参考附加路径，不是工作区信息隔离保证。

## 浏览器与证据

使用独立自写日文夹具，未接真实小说项目或模型。Chromium、2× DPR，1280×900 与 390×844 CSS 像素；窄屏不是实际手机／触控测试。天青、墨分、青绿主题均检查，页面无横向溢出。用途标签及下拉框不挤压，按钮复用既有边框；长引用在容器内换行、可滚动至结束边界。

实际操作覆盖默认不选、选择与预览、明确确认只入队、刷新后任务快照、viewer 可预览但没有确认写入按钮。另通过浏览器在服务器已响应后丢弃一次响应，验证保留确认请求、显式重试返回同一任务；没有启动执行器。随后用真实 CLI 退回夹具来源定稿，浏览器显示“已过期／材料已变化”，仍保留旧原译文与完整引用边界。
