# 1.15.4 验收记录

更新：2026-11-14。本页记录 1.15.4 候选发布时的本地验证范围、已检查项与未测边界。

## 本版范围

- **Web 翻译工作台易用性优化**：人工译稿标记工具条移入右侧译文编辑栏并提示先选中文字；新增「下一空白段（余 N）」跳转、`已填 X/Y 段` 与未填段标记、`Ctrl+S` / `Cmd+S` 保存快捷键及未建立朝廷前置提示；资料页工具栏直接提供「批准上下文」；向导、TBX 导入、评论刷新、TXT 上传单文件移除、全文检索回车提交、通读章节预填与可读位置显示全面完善。
- **后端错误与 CLI/启动脚本**：交稿预检改用可读章组位置并对未定稿阻塞块去重；补齐 `CommentReply` / `CommentAssign` / `TbxExport` / `TbxImport` 的 `--json` 输出；Unix 启动脚本支持复用已在运行的本地服务并改进日志路径与退出提示。
- **文档、截图与版本登记**：更新[翰林院译书指南](../novel-translation.md)、[使用指南](../guide.md)及三张工作台截图；工作区 crate、依赖、`Cargo.lock` 与 `ziyuan-storage::RELEASES` 登记 `1.15.4`，不新增事件类型，不提高旧事件簿读取门槛。
