# 1.2.0 验收记录

本页记录 1.2.0 发布前的检查结果。只写实际做过的检查；没做的检查列在最后，不算通过。各平台发行包由发布流程在推送标签后另行下载验收，结果以 GitHub Release 页面为准。

## 已通过

| 检查 | 结果 |
| --- | --- |
| 开发前基线（1.1.0 原有测试） | 241 项通过 |

| 代码检查 `cargo clippy --workspace --all-targets --locked -- -D warnings` | 通过（Windows） |

浏览器检查使用编造的测试作品与测试令牌，没有连接 syosetu，也没有接真实模型。

## 未测或有限制

- 没有用真实模型跑过初译、审校、修订的完整一轮，也没有长篇连续翻译；译文质量不在验收范围。
- 「待准修订」栏的真实流程用的是本机模拟模型，不是真实模型的输出。
- 两套配色中通用徽记的文字对比度为 3.92 与 4.11，低于 4.5；这是既有的配色变量，本轮未改。
- 系统语言为日文时的日文字形只检查了样式规则，没有在日文系统上实拍。
- `/api/notes?project=` 的按项目筛选没有专门的自动测试。
- 只在 Windows 上测试；Linux、macOS 由发布流程构建与启动检查，没有人工走查界面。
- crates.io 可信发布在推送标签前无法演练，以发布流程的 crates 任务结果为准。
- 文档中的 1.2.0 截图使用虚构的示例文本与本机模拟模型，不代表模型能力。
