## 联网情况

- 在本机用 `ziyuan follow check` 查询公开接口时**超时**，命令按设计报告失败并以退出码 1 结束。因此不能说本机程序已经连上真实接口。
- 另用独立的网页读取工具访问同一官方接口，返回正常，字段与程序预期一致。这只说明接口和字段可用，不代表本机程序联网成功。
- 程序直连接口，不使用系统代理。需要代理才能上网的环境目前无法检查更新。

## 未测或有限制

- 截图工具超时，没有截图证据。
- 只在 Windows 上测试；Linux、macOS 与持续集成没有跑过。
- 没有测试断电或系统崩溃后的恢复。
- 手动检查与 Web 定时检查在同一秒处理同一作品时，命令行的报告可能把这部作品算错（保存的数据不受影响），留待后续改进。
- 没有在真实长篇作品上测量导入大小；32 MiB 限制的提前报错只用小上限的自动测试验证过。
