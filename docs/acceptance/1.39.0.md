# 1.39.0 验收记录

对应提交：本发布提交（`1.39.0`，含前置重构提交 `06e936b6`）。

## 核对项

1. **Windows 原生号舍与运行时模块拆分（零行为变更、零新增事件与玉玺代码）**
   - [`crates/ziyuan-sandbox-windows/src/windows.rs`](../../crates/ziyuan-sandbox-windows/src/windows.rs) 拆分为核心入口（1433 行）与 3 个内聚私有子模块：[`windows/acl.rs`](../../crates/ziyuan-sandbox-windows/src/windows/acl.rs)（259 行）、[`windows/door.rs`](../../crates/ziyuan-sandbox-windows/src/windows/door.rs)（618 行）、[`windows/env.rs`](../../crates/ziyuan-sandbox-windows/src/windows/env.rs)（178 行）；根工作区维持 `unsafe_code = "forbid"`，公开安全接口不变。
   - [`crates/ziyuan-runtime/src/haoshe.rs`](../../crates/ziyuan-runtime/src/haoshe.rs) 将 `#[cfg(windows)]` 号舍编排抽出至 [`haoshe/windows.rs`](../../crates/ziyuan-runtime/src/haoshe/windows.rs)（870 行），跨平台公开符号与重导出保持不变。
2. **Web 前端模块化拆分与 HTML5 嵌套修复**
   - 从 [`crates/ziyuan-web/src/index.html`](../../crates/ziyuan-web/src/index.html) 抽出 [`import-decoder.mjs`](../../crates/ziyuan-web/src/import-decoder.mjs)（多语种严解码，配 [`import-decoder.test.mjs`](../../crates/ziyuan-web/src/import-decoder.test.mjs) 4 条 Node 单测）与 [`command-palette.mjs`](../../crates/ziyuan-web/src/command-palette.mjs)（`Ctrl+K`/`Cmd+K` 命令面板构造与过滤，配 [`command-palette.test.mjs`](../../crates/ziyuan-web/src/command-palette.test.mjs) 3 条 Node 单测），由 [`crates/ziyuan-web/src/lib.rs`](../../crates/ziyuan-web/src/lib.rs) 鉴权 `/assets/{name}` 路由按需动态加载，保留未登录页内联经典脚本零回归。
   - 修复 [`index.html`](../../crates/ziyuan-web/src/index.html) 中 `<div id="cmd-palette">` 误置于 `<head>` 的 HTML5 嵌套错误，将其移入 `<body>`。
3. **稳定性约定补账与版本登记**
   - 在 [`docs/stability.md`](../stability.md) 补齐 `1.31.2`–`1.38.0` 全量兼容边界与非冻结缓存清单（补入 `.ziyuan/index/symbols-v1.json`），同步更新 [`docs/architecture.md`](../architecture.md)。
   - 同步更新 [`Cargo.toml`](../../Cargo.toml)、[`Cargo.lock`](../../Cargo.lock)、[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs)（`RELEASES` 序号 75 `1.39.0`）、[`docs/roadmap.md`](../roadmap.md)、[`docs/README.md`](../README.md)、[`docs/releasing.md`](../releasing.md) 与 [`CHANGELOG.md`](../../CHANGELOG.md)。
