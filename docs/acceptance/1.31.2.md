# 1.31.2 验收记录

对应提交：本发布提交（`1.31.2`，含前置提交 `1021c3b3`、`9bb4fb4c`、`34074739`、`fb67d69d`）。

## 核对项

1. **Windows 原生号舍 8.3 短路径生产修复（`ziyuan-sandbox-windows`）**
   - [`crates/ziyuan-sandbox-windows/src/windows.rs`](../../crates/ziyuan-sandbox-windows/src/windows.rs)：新增 `normalize_win32_long_path`，在 `reject_reparse_point` 之后将 `program`、`cwd` 与 AppContainer profile 路径展开为无 `\\?\` 前缀的标准 Win32 长路径，避免用户名超 8 字符（如 `RUNNER~1`）时 `.NET`／PowerShell 在 AppContainer 内触发 `GetLongPathNameW` 枚举父目录而返回 `UnauthorizedAccessException`。
   - 本地以 8.3 短路径 `TEMP`（`ZIF608~1`）复测 `ziyuan-sandbox-windows` 12/12 与 `ziyuan-runtime` 实时 AppContainer 测试全部通过。
2. **Windows Server 2025 CI 全绿闭环与测试稳健性修复**
   - [`scripts/prepare-windows-null-device.ps1`](../../scripts/prepare-windows-null-device.ps1) 与 [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml)：在 Windows Server 2025 CI 对齐 Windows 11 桌面版的 `\Device\Null` 默认权限（`ALL APPLICATION PACKAGES` / `S-1-15-2-2` / Low IL，Windows 11 桌面端自动跳过）。
   - [`crates/ziyuan-sandbox-windows/tests/startup.rs`](../../crates/ziyuan-sandbox-windows/tests/startup.rs)：PowerShell 验收脚本改用纯 .NET BCL 摆脱干净环境下模块自动发现差异；拆分 `git --version`（必过）与 `git hash-object`（在支持 `GetFinalPathNameByHandleW(VOLUME_NAME_DOS)` 的构建严格校验 40 位 SHA-1，在早期 Windows Server 26100 仅对已知 OS 限制放行且不掩盖其他错误）。
   - [`crates/ziyuan-runtime/src/tools.rs`](../../crates/ziyuan-runtime/src/tools.rs) 与 [`crates/ziyuan-runtime/src/haoshe.rs`](../../crates/ziyuan-runtime/src/haoshe.rs)：移除测试命令对 `>nul`／`2>NUL` 的非必要依赖。
   - [`crates/ziyuan-web/src/text_tests.rs`](../../crates/ziyuan-web/src/text_tests.rs)：补齐 `.header("Expect", "100-continue")`，消除 Windows Winsock 下提前返回 `403` 偶发 `WSAECONNABORTED (10053)` 竞态。
3. **版本登记**
   - 登记补丁版本 `1.31.2`（[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs) `RELEASES` 序号 67，零新增事件与接口变更）。
