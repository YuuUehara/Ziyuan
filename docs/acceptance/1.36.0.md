# 1.36.0 验收记录

对应提交：本发布提交（`1.36.0`，含前置特性提交 `5e919366`）。

## 核对项

1. **多语种确定性 QA 升级（`source_script_leak` 与 `punctuation_mismatch`）**
   - [`crates/ziyuan-app/src/translation/verification.rs`](../../crates/ziyuan-app/src/translation/verification.rs)：新增 `source_script_leak`（按项目原文语种检出中文译文残留日文假名、韩文谚文及法／德文变音原词，屏蔽已批准术语白名单与独立间隔号／长音号）与 `punctuation_mismatch`（检出成对中文标点失配及汉字后紧跟半角 ASCII 标点，自动剥离 URL）。
   - [`crates/ziyuan-web/src/index.html`](../../crates/ziyuan-web/src/index.html) 与 [`crates/ziyuan-cli/src/translation_commands.rs`](../../crates/ziyuan-cli/src/translation_commands.rs)：确定性检查筛选下拉框、问题类型标签与命令帮助同步补齐。
2. **双语对照成稿导出（HTML + Markdown）**
   - [`crates/ziyuan-app/src/translation/html_export.rs`](../../crates/ziyuan-app/src/translation/html_export.rs) 与 [`finished.rs`](../../crates/ziyuan-app/src/translation/finished.rs)：`ExportOptions` 新增 `#[serde(default)] pub bilingual: bool`；HTML 生成双栏响应式离线对照页（沿用 CSP `default-src 'none'; style-src 'unsafe-inline'`），Markdown 生成逐段对照正文，单语导出输出保持逐字节不变，`txt` 格式启用 `--bilingual` 显式拒绝。
   - [`crates/ziyuan-cli/src/text_commands.rs`](../../crates/ziyuan-cli/src/text_commands.rs)、[`crates/ziyuan-web/src/text.rs`](../../crates/ziyuan-web/src/text.rs) 与 [`index.html`](../../crates/ziyuan-web/src/index.html)：接入 CLI `--bilingual`、Web `?bilingual=true` 与成稿导出双语勾选框。
3. **术语表 Excel UTF-8 BOM 导出与按块确定性候选术语提案**
   - [`crates/ziyuan-app/src/translation/materials/termbase.rs`](../../crates/ziyuan-app/src/translation/materials/termbase.rs) 与 [`mod.rs`](../../crates/ziyuan-app/src/translation/materials/mod.rs)：新增 `export_termbase_csv_with_bom`（Excel 兼容 UTF-8 BOM）与 `propose_block_terms`（按语种确定性提取候选术语、跳过现有术语表与草稿词条，仅可写 `translations/<项目>/<块>/proposals/term-candidates.json`，绝不触碰 `context/` 与 `zh.json`）。
   - [`crates/ziyuan-cli/src/translation_commands.rs`](../../crates/ziyuan-cli/src/translation_commands.rs)、[`crates/ziyuan-web/src/materials/mod.rs`](../../crates/ziyuan-web/src/materials/mod.rs) 与 [`index.html`](../../crates/ziyuan-web/src/index.html)：新增 CLI `termbase export --bom`、`termbase propose [--write]`、Web `?bom=1`、`POST /text/{project}/blocks/{block}/term-proposals` 与资料工具栏按钮。
4. **追更来源扩展（Kakuyomu 与通用 HTTPS RSS/Atom Feed，只查元数据不抓正文）**
   - [`crates/ziyuan-app/src/subscriptions/model.rs`](../../crates/ziyuan-app/src/subscriptions/model.rs) 与 [`feed.rs`](../../crates/ziyuan-app/src/subscriptions/feed.rs)：扩展支持 `kakuyomu:<数字ID>`／`https://kakuyomu.jp/works/<ID>` 与显式 `feed:https://<公网域名>/<路径>`；Atom 1.0／RSS 2.0 解析器仅提取标题、作者、条目数与更新时间并丢弃正文节点，内置 DNS／IP 公网核验防 SSRF，禁止端口／凭据／查询串与私有／保留域名；多源入队站名分别为 `syosetu:<code>#<N>`、`kakuyomu:<id>#<N>`、`feed:<sha256前16位>#<N>`。
   - [`crates/ziyuan-cli/src/subscription_commands.rs`](../../crates/ziyuan-cli/src/subscription_commands.rs)、[`crates/ziyuan-web/src/subscriptions.rs`](../../crates/ziyuan-web/src/subscriptions.rs) 与 [`index.html`](../../crates/ziyuan-web/src/index.html)：同步接入多源关注与安全外链校验，前端契约测试完整保留。
5. **文档与版本登记**
   - 同步更新 [`Cargo.toml`](../../Cargo.toml)、[`Cargo.lock`](../../Cargo.lock)、[`crates/ziyuan-storage/src/lib.rs`](../../crates/ziyuan-storage/src/lib.rs)（`RELEASES` 序号 72 `1.36.0`）、[`docs/novel-translation.md`](../novel-translation.md)、[`docs/subscriptions.md`](../subscriptions.md)、[`docs/roadmap.md`](../roadmap.md)、[`docs/README.md`](../README.md)、[`docs/releasing.md`](../releasing.md) 与 [`CHANGELOG.md`](../../CHANGELOG.md)。
